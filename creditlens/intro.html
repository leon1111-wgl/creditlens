一条核查路线

工作台按核查顺序组织：先找到数字和它的位置，再判断能否比较、怎样变化，最后固定成可复核的底稿。每一步都保留输入、规则和未解决的问题。

  1. 查指标

    研究 · 表格取数

    按行名与年份取数。整行、词级和按证据用途三种规则并排，取错与依据不足一同保留。

    打开表格取数 →

  2. 回到原页

    来源与原页

    选中金额、年份表头和行名分别标框，附官方文件页码；保存的定位记录可展开核对。

    查看定位框 →

  3. 核对口径

    单位适用性 · 同名行

    完整读取单位说明后才展开数量级；同名行先由分析员明确所指，系统不替人选择。

    检查单位与同名行 →

  4. 毛利率变化

    研究 · 毛利率变化

    以各公司自身两期数据分解毛利率变化，公式和输入同屏；公司说明与会计计算分开列示。

    打开毛利率变化 →

  5. 研究交接

    研究 · 研究任务

    记录采用理由，固定版本快照，交给另一身份复核或退回；修订后原快照仍可导出。

    打开研究任务 →

季度研究按研究截止日查看微软 FY2025 季度变化与原始依据。文档实验比较定位方法与图像退化下保存的识别结果。

实现范围

工作台只把已实现并经过检查的功能列为可用；其余方向仍在开发中。

已实现

  • 表格取数三种规则对照，保留候选、定位框和评分记录
  • 单位适用性检查与同名行的明确选择、导出和核对
  • 毛利率与经营现金流的确定性分解，Decimal 计算，公式可展开
  • 研究任务：采用理由、版本快照、独立复核与退回、导出一致性核对
  • 文档实验：保存的 CPU OCR 结果、方法对照和图像退化结果

开发中 · 尚未实现

  • 预测模型与组合实验
  • 通用多模态问答与自动公告更新
  • 跨页续表、图表取数和同口径历史材料
  • 独立人工金标准，以及未参与调参材料上的评测

企业数据来自官方历史披露，仓库只保存必要数值、口径和来源定位，完整 PDF 与完整 OCR 不随仓库分发。现有材料属于开发样例；来源可追溯、计算一致，不代表披露真实性或经营原因已获独立证实。
