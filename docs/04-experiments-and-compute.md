## 分阶段验收

| 阶段 | 检查内容 |
|---|---|
| 来源与解析 | 文件版本、页码、单位、期间、原文及定位是否对应 |
| 检索 | Recall@k，以及包含多条必要依据时的全部证据召回 |
| 数值处理 | 输入值、符号、口径、公式、执行结果及异常拒绝 |
| 引用与结论 | 引用是否存在、是否支持具体结论、必要证据是否齐全 |
| 不足与冲突 | 应当停止时是否停止，本可回答时是否过度拒绝 |
| 工程流程 | 权限、重复提交、版本冲突、失败恢复与导出一致性 |

公开结果分开记录软件测试、合成控制和真实材料实验。参考答案由开发过程整理的材料属于开发集，不能转称独立人工测试集。模型自报置信度也不能作为校准后的正确率。

## 比较方法

文字、结构化表格与页图方法使用相同任务、原始文件和评价条件。先保存候选，再读取参考评分；同时报告恢复结果、错误、拒绝和失败原因。多次运行与同源变体不能作为独立样本扩大分母。

未来的检索、重排或模型对照须固定数据划分、基座、上下文与工具调用条件，记录时延、调用次数和运行环境。训练与最终测试按公司、文档及时间隔离；来源许可和人工核验不足时，不把计划写成训练成果。
