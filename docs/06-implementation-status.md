## 当前限制

- 季度模块只处理一个发行人一个财年及整月季度，公告仅有日期时从次日开放；无周历季度、历史修订链、自动批准推导值或模型填补。网页是当前抓取，不是历史版本证明，季度模块已接入只读网页。
- 微软、苹果两份固定数字 PDF 的六页已有原页 bbox 和干净渲染图的真实 OCR 核对；通用 PDF、图表/扫描件理解、跨页续表及更正关系尚未实现。两个来源格式一致不代表真实性鉴定。
- 当前模型接口只做模拟传输测试；没有真实 LLM 质量、训练增益、金融预测、负载测试或用户效率结果。
- 官方数据仍需核查是否适用于目标任务。事实包导入不自动证明材料真实性；现有债务/现金口径不完整。
- API-key 模式不等于 SSO 与企业身份治理；默认 demo 只能本地使用。
- SQLite 哈希链不能抵御拥有数据库写权者重算全链；尚无独立审计存储、删除传播及备份恢复验收。
- 1 MB 请求检查先读体，生产还需入口流式限制。未完成渗透、安全及合规审查。
- Docker 配置已提供，但本机无 Docker，未实跑。Python 包应从仓库根目录运行；v0.5 wheel 已构建并确认包含新 HTML，独立安装运行及样例数据分发仍未验证。
- Starlette TestClient 对 httpx 给出弃用提示，当前测试通过，后续需评估迁移。
- GitHub 项目与主页入口已发布，本机 Git 登录已修复；实现提交 68a55a5 的远端测试通过。连接器先前的写入 403 未单独重测。
- 第 7 轮季度研究实现提交 22168b0 的 [远端测试](https://github.com/leon1111-wgl/creditlens/actions/runs/40160831746) 已通过，主页更新为 d13f771；此前 v0.4 的验收记录继续保留。完整平台仍在建设中。
