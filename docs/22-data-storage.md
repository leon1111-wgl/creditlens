# 数据放在哪里，怎样按需取回

按2026-10-25的最新要求，公开数据产物优先放在GitHub，本地保留运行必要的小文件，不长期留大份下载或重复副本。

## GitHub保存的内容

- [场景数据](../data/demo/research-scenarios.json)：三个业务问题、角色职责、步骤、反馈和预期结果，业务情节与官方事实来源分别标记。
- [场景运行清单](../artifacts/research-scenarios/manifest.json)：三个实际复演终态、四个冻结导出、每步事件与文件摘要。
- [现金流事实包](../data/research/cash-flow-bridge-v1.json)：必要金额、原文位置、来源版本与口径。
- [实际页面下载](../artifacts/research-cash-flow-demo.json)：包含会计分解与复核范围的冻结底稿。

模拟场景不需要拷贝整份财报；复演脚本读取已经登记的小型事实包。再次运行用新的隔离输出目录，不覆盖前次结果。

## 大份原始数据按需下载

原始PDF仍从公司官方渠道取得，FinQA从作者仓库的固定提交取得。项目保存来源URL、版本、大小上限与SHA-256，而不是重复托管权利范围不明确的整份文档。公开可读不等于可以随项目重新授权。

当前常用事实、页面预览和已有结果不依赖PDF常驻磁盘。重新提取整份资料或复跑基准时才需要下载；如果源文件换版导致哈希不同，应停止并重新登记，不自动接受新版本或覆盖冻结实验。

代码仓库的小型事实、公开导出和截图仍会随本地Git检出存在。这些用于运行和检查；“不留大数据备份”不表示删除源码、主应用数据库或尚未保存的研究。

本轮清理结果及按需下载命令在完成远端核对后记录于本页末尾。完整OCR输出和页面证据体积较小且关联历史诊断，暂保留必要本地记录；没有将它们批量公开。

## 按需恢复入口

```bash
# 只列出来源，不联网下载
python scripts/fetch_registered_sources.py --list
# 确实需要复现时，再明确选择一个资产
python scripts/fetch_registered_sources.py --asset msft-fy2025
```

[来源索引](../data/remote-assets.json)登记四份官方PDF和FinQA固定版本。脚本限制HTTPS域名、重定向和最大文件体积，检查SHA-256后才保存；默认输出到 `.run/downloads/`，不覆盖已有文件，不改原事实包。网络控制以模拟响应测试；本轮没有为测试再次下载全部原始数据。[工具与边界](research/2026-10-25-remote-data.md)

完整FinQA开发集移除后，原页内检索实验需要先按需恢复该文件；若在服务中使用，设置 `CREDITLENS_DATASET` 指向下载后的JSON再启动。财务研究与复核模块使用自己的小型登记包，不受这一基准缓存清理影响。已有完整OCR的只读复算仍使用保留的本地记录，缺失时应报告需要恢复输入，不能静默重跑并覆盖旧实验。
