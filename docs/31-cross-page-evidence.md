# 把分散在几页的依据放到一次计算中

研究员想看一家公司的经营现金流净额，相对营业收入有多大。收入在利润表，现金流在现金流量表，合并范围还要到附注里确认。只找到两个数字，未必足够支持计算。

工作台提供四个固定任务：微软和苹果各自FY2024、FY2025的经营现金流净额占营业收入比例。选择两项金额和一项合并范围依据，检查主体、报告版本、实际期间、币种单位、原值与定位后，用Decimal计算。材料缺失或错配时列出缺口，不把缺数填成零。

这是不同报表的多页证据关联。它没有自动拼接同一张跨页续表，也不包含OCR、视觉问答或模型效果评测。

## 输入、正确标准、错误与恢复

| 模块 | 输入 | 什么算正确 | 常见错误 | 发现和恢复 |
|---|---|---|---|---|
| 登记材料 | 已有官方披露事实包、合并范围短定位 | 来源及规范摘要与冻结版本一致；金额和附注保留各自定位粒度 | 重写来源包后仍用旧登记；把工具参考说成人工金标准 | 材料不匹配时停止载入；恢复原版本或另行登记新版本 |
| 选择依据 | 固定任务及三个角色的证据ID | 每个角色恰好一张，且对应任务所需主体、年度及报告 | 收入选了上一年；附注没选；同一个数字重复选择 | 检查逐项显示问题，修正选择后重新计算 |
| 数值计算 | 已通过检查的CFO和营业收入 | 同期合并报表原行、相同单位，分母为正；输入、公式、精度可见 | 负号丢失、缺数当零、把净现金流当收款 | 原始显示值与Decimal核对；缺失或非正收入不算，合法负CFO保留 |
| 原页查看 | 已登记金额卡、当前目录摘要 | 原页版本与登记一致；框只来自已有位置 | 页面缺失时继续显示旧图；为附注虚构细框 | 页面缺失给官方链接，不自动下载；身份或选择变化清除旧图与结果 |

## 具体口径

公式为 `经营现金流净额 ÷ 营业收入 × 100`，结果保留6位小数，使用Decimal精度40和ROUND_HALF_UP。原金额单位均为百万美元，因此比值无需换汇。正常为零的CFO可以计算；“未披露”“不适用”“无法识别”均不能冒充零。分母为零或负数时，本任务停止计算。

这个观察比例不是销售回款率、收现率或利润率。分子已包含经营活动中的收付款；单靠比例升降不能推断客户回款恶化，也不能证实盈利质量。持续经营与终止经营的经济分解未确认，本任务只采用所列合并报表原行。

FY2024使用FY2025报告中的比较列，不是当年可得数据快照。当前仅支持登记材料模式，历史时点请求会被拒绝。两家公司财年日期、天数和业务不同，不在本页作同行排名。

## 依据与页面

微软使用物理第50页的收入、第53页的CFO及第55页合并范围附注；苹果使用第32、36、37页。金额卡保留金额、年份、单位框；范围附注只有此前登记的页码和短定位，不生成没有依据的文字框。

四个任务共有8项金额事实和两处共享范围锚，不能把重复引用的附注算作独立证据。来源是此前固定的官方公开披露；新增关联由工具辅助建立，独立人工确认待完成。原页预览复用既有本地文件和摘要核验，不因此新增识别质量成绩。原图缺失时只提示官方入口，不自动重下。

打开本地 `/cross-page`：选任务 → 选择三个角色的依据 → 检查并计算 → 查看金额原页和检查理由 → 导出本次结果。改选、换任务或换身份会清除旧结果。此页是只读计算，没有保存到研究任务，也不继承现有复核批准。

## 接口和复演

`GET /api/cross-page-evidence` 返回登记任务、证据卡及目录摘要；`POST /api/cross-page-evidence/check`只接受任务ID、所选证据ID和`expected_catalog_sha256`。金额、源文件和审批状态不接受客户端注入。目录变化返回409，重新载入后再检查。API-key模式仍校验身份；固定公共披露目录可由viewer查看，不涉及租户私有底稿。

金额原页由`GET /api/cross-page-evidence/cards/{card_id}/page.png?expected_catalog_sha256=...`读取。先验证身份、目录和金额卡，再由既有VisualStore检查本地页图摘要；附注没有本地细粒度预览，返回明确不足。

```bash
python scripts/evaluate_cross_page_evidence.py
python -m unittest tests.test_cross_page_evidence tests.test_cross_page_materials tests.test_cross_page_api -v
```

复演默认写入新的`.run/reproductions/cross-page-evidence-checks.json`，同名结果不覆盖。正常任务与合成错选／异常分别标注，参考答案不是独立人工题；运行结果不能称模型问答准确率。旧实验和研究审批均保持原样。
