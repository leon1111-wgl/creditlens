# 从整页识别结果里找数字

分析员给出行名和年份，系统能否找到对应金额？原来的文档核对先知道参考框，再检查框里的文字。表格取数实验单独验证候选查找：两种方法接收完整OCR页面、行名与年份，先返回候选或说明不足，再交给评分程序读取参考答案。

## 输入与正确标准

| 环节 | 输入 | 正确标准 | 常见错误与恢复 |
|---|---|---|---|
| 文字顺序取数 | 整页OCR的文字顺序、行名、年份 | 找到唯一行名及年份序列，按统一数字规则选出候选 | 文本顺序错乱、行名重复或金额缺失；保留候选与失败，不能靠参考金额纠正 |
| 版面行列取数 | 同一份OCR，增加既有位置关系 | 行名、表头与金额的位置能建立唯一关联 | 页脚年份混进表头、同名分区、合并多金额或符号歧义；返回不足并列原始观察 |
| 事后评分 | 已完成的候选与固定参考 | 金额、定位和未回答情况分别统计，全部查询进入分母 | 数字偶合但位置错、删掉拒绝样本；分别报告错取和不足，不作成功样本筛选 |
| 保存结果与查看 | 经过登记的实验文件及发布摘要 | 来源、配置、实现和案例集合匹配，页面清楚展示验证范围 | 文件被修改或来源版本变化时拒绝读取；完整重放使用原OCR，另写新结果 |

两种方法使用同层OCR输入与相同数字、置信门槛和单位策略。单位原文可以说明百万等数量级，但不能据此补出美元；年份列也不等于已经建立完整起止日期、报表范围或历史可得时间。候选不会自动写入已采用事实或批准研究底稿。

## 材料与实验边界

微软50、52、53页及苹果32、34、36页的完整OCR已在此前实验中运行并保留。取数复演只读取这些结果，不再下载PDF、生成完整页图或调用识别模型。公开结果只保留必要的查询、候选证据、固定参考和摘要，不包含完整OCR。

使用既有42项事实作为开发查询，包含正确值、零、同名分区和易混年份。收入与经营现金流两类指标的8项查询可作阅读入口，但完整统计保留42项。材料已经用于前期开发；参考答案和位置并非新的人工独立标注，不能将结果称为未见公司盲测、通用问答准确率或新模型识别成绩。

研究使用者最需要知道的是“具体取到了什么，凭什么选它，何时该停下来”。几何取数规则不属于模型训练；一项候选与参考相等，也不能确认整张财报或经营解释正确。

## 如何查看

打开本地 `/table-lookup`，载入保存实验 → 选择公司、结果范围和行名年份 → 并列看两种方法 → 展开原始文字和定位 → 必要时查看已保留原页 → 导出全部记录。“完整实验统计与方法变化”始终包含所有查询，筛选不会缩小成绩分母。

改选、过滤、重载或切身份后，旧图片和迟到响应不得混入当前视图。原图缺失会提供官方来源入口，不自动下载。页面读取保存结果；重新提取需显式运行复演脚本并提供已有OCR目录。

`GET /api/table-lookup`先校验身份，再检查保存报告；`GET /api/table-lookup/cases/{case_id}/page.png?expected_report_sha256=...`从登记案例取得文档与页码，并校验本地原页。没有任意文件路径或客户端金额写入入口。快照核验与使用完整OCR重跑分别标注，避免把文件内部检查当作再次推理。

左侧导航在13个工作页面保持一致。表格页按资料与指标、方法结果、来源与原页排列；行名搜索仅筛选左侧记录列表，点击具体记录才切换当前查询。原始下拉选择仍可使用。来源区的“展开阅读区”可放大当前原页，按 Escape 收起并返回按钮焦点；不会重新下载或复制另一份证据。窄屏将来源区排列到结果下方，表格在自身容器内横向滚动。

## 当前结果与复演

两种方法在42项已观察开发查询上均为26项金额与位置符合参考、0项错取、16项不足；未观察到真实样例净增益。六个合成控制单独统计。独立人工金标准仍为0，不能将这些数值当作通用文档问答准确率。[正式报告](../artifacts/table-lookup-report.json)保留每一项。

```bash
# 校验公开保存结果；不读取完整OCR，也不重新抽取
python scripts/evaluate_table_lookup.py --verify-saved

# 本地已经保留登记OCR时，重新取数并写入一个新的文件
python scripts/evaluate_table_lookup.py --ocr-root .run/document-ai --output my-table-lookup-replay.json
```

新文件位于`.run/reproductions/`，已有同名文件时拒绝覆盖。没有完整OCR时只能执行保存结果核验，不会自动下载。页面截图见[桌面视图](images/table-lookup-workspace.png)。

## 设计依据

该实验将“找到金额”与[核对已知框](13-document-ai-experiment.md)分别验收。表格与正文关联、独立原文确认、跨页续表、视觉检索和视觉语言模型仍各自需要材料与验收。
