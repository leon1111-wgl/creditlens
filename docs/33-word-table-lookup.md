# 用更细的位置查找财报金额

上一轮按行名和年份寻找金额时，部分整行识别结果把数字与旁边的符号放到一起。词级位置能否把它们分清，需要对照实验。本轮使用已经保存的原始词框，保留父行与每个词的来源，比较同页的整行方法与受约束的词级方法。

使用者仍是核查财务指标的研究员。目标是把能确定的金额与依据交给人核对，把不能确定的部分说明白；词框更细不自动表示结果更准确。

## 输入、判断与恢复

| 环节 | 输入 | 正确标准 | 失败与恢复 |
|---|---|---|---|
| 同输入对照 | 六份已保存WordPage及固定行名、年份 | 父行投影与旧行级OCR摘要相同，42条登记记录全部保留 | 输入或来源不同就拒绝复演，不能直接将差异归于词框 |
| 词级候选 | 原生词、父行、表头列关系 | 父行文本完整保留，符号及金额有唯一列归属，原词可追查 | 文本缺失、跨界、未归属符号、低分或同名行保留不足，不借参考框纠正 |
| 事后评分 | 先固定的候选、既有金额与位置参考 | 分别记录匹配、错取、不足及逐题转移 | 新方法的回退仍进入分母；合成控制与实际材料分开 |
| 页面比较 | 验证后的保存报告 | 当前实验、案例、图像和导出来自同一快照 | 改实验、身份或案例时清空旧视图，旧请求不可覆盖新选择 |

单个金额可以由多个原始词组合，但组合框是派生结果，不是新模型输出。完整父行与原生词同时保留，不能删掉一个负号后把正数当作正确候选。父行和词的识别分数也不是已经校准的财务正确概率。

## 材料与边界

本轮复用此前识别的微软50、52、53页和苹果32、34、36页，共725个父行、1,381个原生词。六页的父行投影与第29轮行级输入逐字段一致。没有重新下载PDF、页面图或完整OCR，没有新的模型推理和训练。

页码、行名、年份来自已有登记，材料已经用于开发；参考金额和框只在取数后评分。独立人工核验仍未完成，不属于未见公司测试。年度列与数量级也不等于完整期间、币种或财务范围已确认，候选不会自动加入已采用底稿。

42条登记记录实际对应40组不同查询输入。苹果`Term debt`在2024与2025各有流动、非流动两份参考，但给定行名、年份和页面相同。两份记录保留在完整分母中，并显示各自编号；取数不接收这些分区答案，相同输入必须产生相同候选。不能将它们写成42个独立问题。

整行与词级比较同时涉及细分位置和保护条件。新增保护可能减少错误，也可能增加不足；结果应逐项解释，不能全部归因为“多模态更准确”。[上一轮整行结果](32-table-lookup.md)保持原样。

## 实际对照

| 方法 | 金额与位置匹配 | 错取 | 不足 |
|---|---:|---:|---:|
| 相同输入的整行方法 | 26 | 0 | 16 |
| 带保护条件的词级方法 | 22 | 0 | 20 |

42条记录中，22条保持匹配、16条保持不足、4条由匹配退回不足，没有新增匹配。微软两年的短期债务因词框越过父行停下；苹果两年的收入同时存在原生词低分与词框越界。不能据此认定披露金额有误，也不能把零错取解释为通用准确率。

这一版本保留整行实验作为默认入口，词级结果作为单独对照。七个合成控制另列，不能代替实际材料效果。完整逐项结果见[实验报告](research/word-table-lookup-experiment.md)。

## 查看与复演

在 `/table-lookup` 选择“细分位置：整行与词级”并载入，先看完整统计及三乘三变化表，再选择具体查询。展开候选的父行、原词和处理记录；必要时回到已保留的原页，最后导出整份记录。切换实验后必须载入对应结果，不能沿用旧图或旧下载。

公开保存结果的核验只检查来源登记、发布摘要与候选评分。使用完整WordPage重新抽取需要显式提供本地输入，重新生成结果文件；它与保存报告核验分别记录。

```powershell
python scripts/evaluate_word_table_lookup.py --verify-saved
python scripts/evaluate_word_table_lookup.py --ocr-root D:/acl-xwf/creditlens/.run/reproductions/document-ai-words --output word-table-lookup-new.json
```

第二条命令需要此前保存且摘要一致的六份WordPage，输出同名时拒绝覆盖；输入缺失时停止，不自动下载。原页查看还需要本机保留对应图像，缺失时显示官方来源入口，其他记录与导出仍可查看。
