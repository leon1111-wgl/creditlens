# 分别记录原文，再冻结参考候选

使用者是负责财务文档标注和实验验收的研究员。先选定来源、页面和问题，由两个不同应用身份分别填写观察，收齐后比较内容，再交给未参与填写的复核身份决定是否冻结。系统保存参考候选，不自动修改原有财务事实或实验成绩。

## 为什么需要这一步

[词级对照](33-word-table-lookup.md)没有增加实际匹配，四项记录回退到不足。继续对同一批参考调门槛，不能证明新方法更可靠。需要先让参考本身可以逐项核对：谁看了哪版材料，填了什么，分歧在哪里，修正是否改变了旧实验。

## 一次核对怎样完成

1. 在`/reference-review`载入目录并选任务。目录只提供公司、原页、行名、年份和来源登记，不发送旧金额、参考框、模型候选或债务分区答案。
2. 新建记录后查看未标注原页，填写完整金额字面值、单位原文、分区依据和定位。可以点选原页的两个对角，也可以填写PDF点坐标。歧义、无法辨认和证据不足分别记录，不填零。
3. 本人的观察提交后封存。第二份到达前，其他身份只能看见提交状态，不能通过当前记录的响应、摘要或事件读到该份内容。
4. 第二个不同身份填写后显示差异。比较保留完整符号、数值、单位、币种原文、位置和分区；自由原因文字单独保留，不因措辞不同自动判定金额分歧。
5. 未参与填写的复核身份可以冻结两份一致的候选。分歧不能强行改成一致，应关闭当前核对记录，说明原因再建立新记录。旧冻结导出始终保留，重开不会替换旧评测参考。

已有材料及旧答案已经公开，所以这是当前流程中的提交隔离，不是全应用盲测。两个账号不证明两位独立真人；`human_gold=false`与`independence_not_verified=true`始终保留，不能通过表单自报升级。当前40组查询来自已用开发材料，42条旧参考的映射仅在服务端，不算新增独立测试题。

## 四句话验收

| 模块 | 输入 | 正确标准 | 可能错误及恢复 |
|---|---|---|---|
| 问题目录 | 固定来源与查询 | 40种不同输入，无预填答案；来源版本可查 | 混入旧答案或分区时拒绝；登记变化后重新绑定 |
| 原文观察 | 状态、完整字面值与上下文 | 金额完整解析、坐标有效，非答案保留原因和空值 | 数值截取、丢符号、空坐标变零时拒绝；改正后重新提交 |
| 分别提交 | 服务端身份、版本、幂等键 | 不同用户ID各提交一次，第二份前隐藏对方内容 | 重复身份、旧版本或跨租户拒绝；网络结果不明时重试同一请求 |
| 复核与冻结 | 两份一致观察与第三身份 | 绑定当前登记和版本，冻结候选不自动采用 | 自审、分歧或登记漂移禁止冻结；第三身份可关闭失效记录后另建 |
| 历史导出 | 冻结版本 | 保留原始内容与摘要，后续更改不覆盖 | 当前来源不可用仍能查看旧记录；不能把历史一致当成当前适用 |

两人对金额框稍有不同也会显示差异；本版没有未经验证的定位容差。冻结“依据不足”或“存在歧义”的一致观察时，状态仍然是不足或歧义，不生成可计算金额。

## 权限与实现

沿用FastAPI的API-key身份与租户范围。分析员、复核员可提交观察，只读身份不能写；复核操作额外检查当前记录的参与者。SQLite事务、条件版本更新和幂等请求记录防止重复提交覆盖。单次提交后不可直接编辑，更正通过关联此前记录的新记录完成。

前端按身份、所选记录和原页请求隔离迟到响应。创建与观察提交遇到不确定结果时保留原请求及幂等键；冻结结果不明确时先重新读取状态。服务端仍执行身份、来源和版本约束，不能靠页面禁用按钮代替。

原页仅用已保留的本机图像，字节摘要必须匹配当前任务快照；缺失时显示官方来源入口，不自动下载。目录和观察都只作为数据，不执行其中的文字。完整流程需要两名观察身份与一名独立复核身份；默认演示角色只有两个可写身份，不能冒充三人流程。

## 当前限制

这是参考准备与协作功能，未完成真实人工标注、独立测试集或新模型实验。软件回归中的角色、观察值和定位均为明确标注的模拟输入，不是财务参考。人仍需确认原文、完整口径和独立性；坐标、字面值和流程状态正确也不能证明原始披露真实。

## 实际验证

新增22项契约、24项存储与复演、7项API测试；全套997项运行995通过，2项因Windows符号链接权限跳过。24项页面状态控制与18项合成复演通过。实际浏览器完成两个模拟观察身份、第三模拟复核身份的冻结和下载；5,479字节下载在另建记录后仍与原API响应一致。原页无旧参考框，换身份清理旧内容，终态和只读身份不显示填写表单。

保存后的旧版本回放会另行重读当前记录；重读失败时明确说明显示的是操作返回版本，并要求读回后继续写入。500、无效JSON及迟到响应的异常路径通过可控脚本验证，未在真实浏览器中注入网络故障。手动两角坐标换算通过页面脚本控制，实际浏览器验证了原页显示与坐标输入。
