# 毛利率变化怎样拆开看

投研和风险分析中，知道毛利率升降只是第一步。还需要核对收入和成本是否来自同一范围，哪些分类变化在算术上贡献了差值，以及哪些经营原因尚无证据。本页新增一个只读的毛利率分解任务，使用微软与苹果 FY2025 报告中 FY2024、FY2025 两列数据。

## 输入、正确标准与失败处理

| 项目 | 约定 |
|---|---|
| 输入 | 每家公司两年，每年两类收入、两类成本、总收入、总成本和披露毛利；共 28 项来源记录 |
| 正确标准 | 同一公司、报告版本、单位、合并范围和稳定分类；全年相邻；分类之和与总额精确相等，总收入减成本与披露毛利精确相等 |
| 常见错误 | 收入与成本错配分类、把金额毛利当成百分率、混用年度或币种、将未知填零、将上年比较数当成上年已可得信息 |
| 发现与恢复 | 核验输入、金额原文与来源绑定；条件不符返回阻断原因。文件或实现变更导致旧实验不再复算时停止展示，保留旧文件，另行登记和重跑 |

产品／服务是本张利润表的收入分类，不能写成经营分部。微软保留 `Product`、`Service and other`；苹果保留 `Products`、`Services`。本任务仅作公司自身两期比较，不把两家分类视为经济含义相同，也不作同行排名。分类毛利是计算值；总毛利是披露金额，不能直接当作毛利率。

## 计算方法

令分类收入为 Rᵢ、成本为 Cᵢ，总收入为 R；分类毛利率 mᵢ=(Rᵢ−Cᵢ)/Rᵢ，收入占比 wᵢ=Rᵢ/R，总毛利率 g=Σwᵢmᵢ。

采用两期均值的对称恒等分解，结果单位为百分点（pp）：

```
构成贡献 = Σ(w₁ᵢ−w₀ᵢ) × (m₁ᵢ+m₀ᵢ)/2 × 100
类内贡献 = Σ(m₁ᵢ−m₀ᵢ) × (w₁ᵢ+w₀ᵢ)/2 × 100
毛利率变化 = 构成贡献 + 类内贡献
```

这是双线性恒等式的对称分配方式，不是因果模型，也不是某篇论文的实验复现。收入权重与分类毛利率都变化时，交互项由两期均值对称分摊；采用其他分配约定可能得到不同贡献，因此公式与方法必须随结果保存。

| 公司 / FY2024 → FY2025 | FY2024 毛利率 | FY2025 毛利率 | 总变动 / pp | 构成 / pp | 类内 / pp |
|---|---:|---:|---:|---:|---:|
| Microsoft | 69.764444% | 68.823742% | −0.940701 | −0.411185 | −0.529517 |
| Apple | 46.206350% | 46.905164% | +0.698814 | +0.616372 | +0.082442 |

显示值为六位小数，微软两项显示后加总与总变动相差 0.000001 pp；界面保留该舍入差，不修改数值凑齐。底层使用 80 位 Decimal 精度和单独的恒等式残差检查。实验另外用 Fraction 有理数运算复核两家固定输入，不能因此推断原始材料自动识别无误。

类别收入为零或负数时不计算该桥。类别成本高于收入时保留负毛利，不取绝对值；负成本超出当前契约。微软两期日历年相差一天会提示，不做按日年化；周历年长度不同会拒算。

28 项金额来自已保留原页的 AI 辅助目视整理，并复用已有 OCR 父行、表头与单位位置。独立人工确认状态为 pending，人工金标准数量为零。新源包保留每项原文金额、归一值、角色、年份、来源哈希和 OCR 父行快照。部分父行包含相邻美元符号，框只作近似定位，不作为精确金额框的评测标准。没有新增模型识别、重新下载 PDF 或完整 OCR；旧 42 项事实和已有实验不被替换。

这条链路将页面、表格结构与数值计算联系起来，但此次增量是来源登记与受限计算，不能表述为视觉模型已经学会解释毛利率变化。FY2024 数据是 FY2025 报告的比较列，不是 FY2024 时点可得性证明。公司原因说明、定价／销量／成本驱动及独立核实仍需更多证据。
