# 保存或提交后没有收到结果，怎样继续

研究任务与解释补充底稿现在支持保存、提交、退回和复核确认的同请求重试。主要解决一种情况：服务端已完成写入，浏览器却因网络或响应异常没有收到结果。此时既不能简单认定失败，也不应再创建一个相同操作。

## 输入、验收、错误与恢复

| 项目 | 要求 |
|---|---|
| 输入 | 当前身份、研究或补充稿ID、操作、预期版本、原提交内容；复核还绑定快照摘要。页面为每次新操作生成独立幂等键 |
| 什么算正确 | 同一请求只执行一次，重试返回首次完整响应；页面另外读取服务端当前版本，不能用旧回执覆盖后续更新 |
| 常见错误 | 写入后响应丢失、回读失败、同一键被用于不同内容、过期版本、身份或租户改变、回执存储失败 |
| 怎样发现和恢复 | 结果不确定时保留原请求并显示重试入口；明确拒绝时保留草稿；版本冲突可选择放弃本页未保存改动并重新载入；回执写失败则整个事务回滚 |

## 页面操作

正常保存后，页面显示已确认的操作及当前服务端版本。连接失败、响应不是有效JSON或服务器返回5xx时，页面保留原始请求正文和幂等键，暂停编辑、切换任务和其他写入。点击“重试原操作”使用同一请求，不重新组装当前表单。

收到首次结果后仍需读取当前记录。如果其他人员已推进版本，页面展示新版本，并说明首次回执没有覆盖它。当前版本回读失败时，继续保留重试入口；列表刷新失败不会再次执行已完成的写入。

明确的4xx拒绝会解除待确认状态并保留表单。若此前出现过连接异常，本次被拒绝不证明第一次没有成功，仍应重新载入服务端版本。对未保存的表单，只有明确点击“放弃本页未保存改动并刷新”才用服务端内容替换；载入失败时原表单继续保留。

切换身份会清除当前活跃的待确认请求和内容，旧身份的迟到结果不能恢复它们。待确认请求也保存在同一标签页的会话存储中，刷新后的恢复见下节；仍不提供自动提交或通用后台任务恢复。

## 刷新后继续核对

点击保存或提交时，页面先把原请求和幂等键写入 `sessionStorage` 并读回核对，再发网络请求。保存的是这次操作及其中的备注、采用决定等正文，不保存 API key、访问令牌或完整服务端响应。尚未点击保存的表单改动不属于恢复记录。

刷新后先连接服务端身份。租户、用户和角色一致，且记录的版本、结构和请求目标都符合固定规则时，页面只读取对应任务的当前版本，不自动写入。点击“重试原操作”才复用原正文、原预期版本和原幂等键；即使当前版本已经推进，也不会把旧请求改成一个新操作。

本地恢复记录的检查先于任务列表加载。列表暂时不可用或返回无效JSON时，页面仍显示待确认操作，不能把列表失败当成“没有待确认操作”并开放新建。对应底稿已成功读取后，可以主动重试原操作；底稿本身尚未读到时，则先使用“重新核对待确认操作”。恢复不依赖先加载完整任务列表。

| 情况 | 页面行为与处理方式 |
|---|---|
| 对应任务已经载入 | 显示原操作名称、原版本及任务标识，当前已保存内容另行显示；可主动重试 |
| 任务列表加载失败 | 单独显示列表错误；已经恢复的原操作与对应底稿继续保留，不自动新建或重发 |
| 当前记录未读到或不对应 | 保留待确认记录，暂停重试；“重新核对待确认操作”只重读，不代替写入 |
| 身份不同 | 不显示正文，不发原操作；连接原身份后继续核对，或明确放弃本地记录 |
| 记录损坏、未知版本或非法路径 | 不执行记录中的目标；提示核对服务端，再明确清除本地记录 |
| 存储不可用或达到上限 | 写前失败会阻止发出本次请求，表单仍保留；恢复存储访问后重查 |
| 已确认，但本地清除失败 | 保持待确认状态，阻止新写入；可用原请求重试确认，或明确清除 |

清除本地记录不会撤销服务端已经完成的保存、提交或复核。页面要求明确勾选放弃后才能清除，再重新载入工作区；如果结果仍不确定，应先查服务端记录。两个业务页面使用不同的记录空间，不能拿解释补充稿的请求写入研究任务。

本地记录限制为64 KiB，原请求正文限制为48 KiB；只接受四个已有保存／操作端点，额外字段、重复JSON键和超深结构拒绝。记录本身可以被本机或同源脚本访问、修改，因此不是加密保险箱或授权凭证；服务端仍执行权限、版本和复核规则。支持范围为同一标签页刷新，不承诺关闭标签页、换浏览器或换设备后的恢复。

## 事务与兼容性

四个已有PATCH及操作接口新增可选`Idempotency-Key`，长度8至128字符。不带键的调用沿用原CAS版本行为。带键的请求在同一SQLite事务内完成业务更新、事件、快照及回执写入，任一步失败不留下成功一半的结果。

回执按租户及幂等键索引，绑定用户、角色、实体类型、实体ID、动作及规范化完整请求。相同租户内复用键而改变任一绑定时拒绝，其他租户的键独立。回放前重新检查角色、对象访问范围及参与者自审限制；回执不是授权凭证。

回执返回首次响应，因此可能是历史版本。历史内容和事件摘要用于检查存储一致性，不能证明管理员没有同时改写全部内容。重试已提交操作不重新读取当前来源或重新批准；它只取回已经完成的事务结果。新的操作仍按原有来源、版本、角色及复核规则执行。

旧研究记录、旧快照、旧导出结构与冻结实验保持原样；写入恢复不会新增金融事实、独立人工参考、模型训练或预测能力。数据验证与模拟故障范围见[写入重试说明](research/research-write-retry.md)和[服务实例重建复演](research/research-restart-cases.md)。
