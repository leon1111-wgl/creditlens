# 金额找到了，单位是否适用于这一行

财报表头常写“以百万计，每股金额除外”。如果只识别开头的“百万”，后续换算就可能把每股金额、股数或另一种数量级也一并放大。此前取数规则保留了完整单位原文，但只匹配量级前缀；合成反例证明，未知的按行、按年例外会被静默接受。

新增检查把完整单位说明与查询行名一起核对。它读取已经绑定来源的取数结果，独立给出单位适用性，不改写旧候选、参考评分或冻结报告。旧方法的“选出候选”不能代替这一步，也不代表该候选已经采用为财务事实。

## 输入、正确标准与失败恢复

| 环节 | 输入 | 正确标准 | 常见错误与恢复 |
|---|---|---|---|
| 读取单位说明 | 原行名、保存提取结果、原单位文字及定位证据 | 完整语句符合明确支持的语法，原文与字段对应 | 未知尾缀、多个量级、缺括号或证据错配均保留问题；回到原文核对后另行登记，不截取开头使其通过 |
| 判断例外是否适用 | 支持的例外类别与明确行类别 | 不把每股、股数、面值或类别不明行套入主数量级 | Basic、Diluted 等需要更多上下文，无法确认时停止；有限行类别规则不是通用财务语义模型 |
| 展开数量级 | 已选出且证据合格的完整数值、确认适用的量级 | 使用 Decimal 展开数量级，保留原值及乘数 | 原方法未选出、低分或单位不足时不输出展开值；不补零，不自动推断币种 |
| 页面与导出 | 当前实验、方法及可选的明确原行 | 返回对象和来源摘要与当前选择一致，保存原始响应 | 更换身份、样例、方法或原行后清空旧结果；来源改变后重新载入，网络失败可重试 |

## 工作台中的用法

打开 `/table-lookup`，选择“按证据用途：三种方法对照”并载入实验。在“单位量级与例外”中选择文字顺序、整行、词级或按证据用途结果，再点击“核对单位适用性”。若要检查同名行的显式选择，先查看全部同名行并选定原行，然后选择“本次明确选择的原行”。

结果分别保留原候选、完整单位原文、是否能展开数量级及拒绝原因。导出的是本次检查的原始 JSON 响应。原自动取数实验、选行导出与事后参考仍可查看；新检查不会写入研究底稿或继承复核批准。

“单位量级符合规则”只说明支持的原文规则可以应用于这项候选。币种、完整财务期间、报表范围仍未确认，不能因此进行跨公司比较。`$` 也不能自动解释成 USD。该检查不证明 OCR 正确、材料真实或公司解释成立。

## 复演与边界

`python scripts/evaluate_unit_applicability.py --verify-saved` 重新核对保存报告。读取既有小型来源与已核验提取记录，不重新下载 PDF、不调用 OCR，也不覆盖旧实验。需要生成新结果时使用脚本的独立输出参数；同名输出不覆盖。

当前材料是此前已经用于开发的微软和苹果六页，单位检查次数、不同查询数和显式选择路径分别统计；人工构造的单位反例另列。没有新增独立人工金标准、新公司盲测或模型成绩。完整语法、数据范围与实际验证见[核心契约](research/unit-applicability-contract.md)和[实验说明](research/unit-applicability-experiment.md)。
