# CreditLens 页面设计规范

本轮目标：让分析员在统一的工作区中查看财务概览、追查原始证据和进入复核。2026-10-26 首版在 `design/banking-workspace` 本地分支实现，尚未合并或部署。

## 视觉与结构

- 延续英文和数字 Times New Roman、中文宋体类字体；蓝色主操作 `#2856a6`、正文 `#1f2329`、背景 `#f5f6f8`、侧栏 `#f0f2f5`。通过、不足和冲突继续使用各自的语义色。
- 所有 13 个业务页面使用同一导航清单：研究工作区、证据核验、材料与实验。侧栏保留案件队列与接口文档，实验室保留 FinQA 来源入口。
- 共享侧导航显式占满侧栏内容宽度并清除旧页 `nav` 的自动边距与最大宽度。菜单紧接品牌区域，不随窗口高度居中漂移；桌面与手机抽屉沿用同一内边距。
- 页头展示当前位置；有身份控件的页面保留原控件及原业务处理器。正文宽度、分栏、字号、控件、边框和表格密度使用统一规则。
- 信用复核页把案例条件放入可展开区域。已载入案例后收起，财务概览、证据台账、复核和操作记录保持原数据与流程。
- 正文、日期、单位和限制说明保持可读对比度。留白服务分组，表格独立横向滚动，财务数字使用等宽数字排版。

## 动效与键盘

- 控件悬停和按下反馈约 130ms；导航收放 240ms；现有视图和详情进入 220ms。共用缓动，内容不依赖动画才可见。
- 不动画改写财务数值，不制造实时刷新或假进度。现有隐藏和显示状态仍由业务代码控制。
- 系统启用 `prefers-reduced-motion` 时关闭过渡和进入效果；偏好改变时只取消设计层创建的动画。
- 窄屏导航作为抽屉：背景内容不可交互，Tab 在抽屉内循环，Escape 关闭并恢复焦点。新建案件先关闭抽屉，再聚焦日期。
- 表格只有在可见且实际横向溢出时显示滚动提示，并成为有名称的键盘滚动区域。使用原生方向键与 Tab，不拦截表内选择框和输入框；宽度足够、表格隐藏或所在详情收起时撤销设计层增加的焦点与提示。已有 ARIA 与焦点设置保留。
- 900px 以下使用抽屉；600px 以下压缩页头和边距。手机上仍能访问案件队列。

## 实现边界

`creditlens/static/workspace.css` 与 `workspace.js` 提供共享外观及渐进式界面增强，HTML 显式引用。静态资源仅从专用目录公开，并随 Python 包携带。原有页面业务脚本、业务 ID、数据、公式、权限及审批流程保持不变；设计层只替换新建案件按钮的滚动/焦点表现。

验证应包括桌面、平板、390px 窄屏；查看真实载入后的表格、长文本、缺失状态；检查导航、键盘、原文查看和导出。浏览器截图不代表模型效果、来源真实性或生产部署。

## 参考

2026-10-26 核验官方资料：

- [J.P. Morgan Salt](https://www.saltdesignsystem.com/salt/patterns)：金融业务组件组合、密度与统一间距。
- [Microsoft Fluent 2 Navigation](https://fluent2.microsoft.design/components/web/react/core/nav/usage/)：导航分组、位置反馈与窄屏适配。
- [Atlassian Motion](https://atlassian.design/foundations/motion)：一致的微交互、面板过渡和减少动态效果。
- 2026-10-27 补查 [MDN overflow 可访问性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overflow#accessibility)：滚动容器的键盘焦点、区域角色与可访问名称。

本项目使用原生 HTML/CSS/JavaScript；未引入上述厂商组件库，也不代表与其有合作关系。
