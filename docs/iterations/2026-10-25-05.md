# 第 5 轮：让主页先讲清楚项目能帮什么忙

日期：2026-10-25。版本仍为 v0.4.0。本轮按用户反馈调整项目介绍，没有新增程序功能或模型实验。

## 为什么改

原来的主页一开头列事实数量、测试数量和实现术语，读者仍然很难知道这个工具拿来做什么。信贷和投研人员首先需要知道：能否帮助检查现金流和债务、找到数字出处、整理疑点，以及把分析交给同事复核。

岗位与竞品判断沿用同日 [第 1 轮调研](2026-10-25-01.md) 的官方岗位及产品资料；没有新增市场调查、客户访谈或竞品测试。这次调整表达，继续围绕同一个财报核查任务。

## 改成什么

主页和项目 README 先说明“帮信贷和投研人员查财报、看现金流和债务压力”，再分开写三件事：

- 现在能用：在微软、苹果公开财报案例中查看数据、核对原文、记录疑点、交给另一位复核人员确认并导出底稿。明确这是本地演示版。
- 接下来准备推出：更多企业和中文财报、新旧公告对比与分析更新提醒，以及在线演示。
- 后续探索：AI 理解复杂文档、附原文的财务问答、现金流预测与风险预警，以及 AI 失败时转交人工的处理。

测试和评测数据继续保留在 README 技术章节和验收报告，主页不再堆砌这些数字。同步更新主页条目源文件和 AGENTS.md，让后续自动迭代沿用这个写法。

## 如何检查与限制

逐句对照当前实现和路线图，区分已实现与计划；检查本地文档链接、Git 差异及主页条目与源文案的一致性，只改主页中的 CreditLens 条目。本轮是文案修改，不增加或重记功能测试成绩。

在线演示、通用文档理解和预测仍未完成，不能因文案改写就视为已经上线。下一步继续推进公告版本关系、更多报告的文档解析验证和模型实验。
