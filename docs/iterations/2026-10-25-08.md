# 第 8 轮：统一主页介绍，讲清数据更新与服务器需求

日期：2026-10-25。本轮按用户要求修改项目名称与介绍，并回答“是否实时、是否需要服务器训练”；属于文档与展示更新，没有新增模型或在线数据功能。

项目展示名统一为 **CreditLens · 多模态金融研究与风险分析平台**。个人主页和仓库 README 分开说明整体用途、已经能用的功能、正在推进的功能与研究方向。仓库侧栏原来仍是英文的企业信用复核介绍，本轮同步改为新平台定位，并明确开发中、历史数据及模型实验尚未完成。

当前功能使用保存的官方历史披露，可以即时计算这些数据；尚无自动公告更新、实时行情或持续预测。每两小时的开发迭代不等于每两小时刷新产品数据。将这一区别写入主页，避免用户误解功能状态。

服务器需求按用途拆开：当前文档与指标工具在本机 CPU 上运行；自动更新需要持续运行的数据任务；在线访问需要应用托管；模型推理与训练则另作选择。现阶段不租 A100，不发生收费 API 或训练支出。数据、评测和训练脚本准备好后，才依据短任务实测提出租卡建议。

继续沿用同日 [岗位与企业调研](../01-product-requirements.md) 和 [平台与论文方案](../11-financial-research-platform.md)，本轮没有新增招聘或竞品结论。对投研和风险使用者，知道数据截至何时、模型是否真正运行过，是判断结果能否使用的必要信息。

验证范围：核对主页替换只影响 CreditLens 条目，保留其余项目和个人经历；检查 Markdown 本地链接和 Git 差异；回读已发布内容。代码未变，不新增测试或把前一轮 103 项测试写成本轮重新运行的结果。个人静态网站中没有找到 CreditLens 旧条目，本轮未改动其页面。
