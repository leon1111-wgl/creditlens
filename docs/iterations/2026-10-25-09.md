# 第 9 轮：把季度研究接到页面，并让独立分支挑问题

日期：2026-10-25。版本 v0.5.0。用户要求完整迭代，并设立调研分支提出建议；随后要求按 LoopDesk 的方式讲清项目用途、企业需求和技术。两项要求在同一轮落实。

## 为什么做

投研和风险分析员需要从一个研究日期出发，看公司经营变化，再追查数字的出处。上轮只有脚本，使用者要阅读 JSON，容易忽略单季与累计、直接披露与推导的差别。本轮把这条操作路径接通，范围保持为微软 FY2025 公开历史样例。

岗位与痛点沿用 2026-10-25 的 [需求调研](../01-product-requirements.md)：金融数据处理、模型验证、Agent 工具和工程交付是相关岗位的能力要求。没有新增客户访谈，也没有验证节省工时的比例。竞品方面，独立顾问核查了 Qlib 已有 PIT 数据库；不把时点查询包装成独创。要检验的是原文、口径、时间、计算与复核能否跟随一个研究结果，参见 [顾问报告](../research/2026-10-25-advisory-01.md)。

## 独立分支给了什么建议

新建 Git 分支 `research/advisory` 和独立工作目录，由研究顾问只写建议，不直接改主产品。研究提交为 `d2344fe`，主分支审读后纳入。

采纳三项建议：本轮完成最小季度页面；下一轮补多公司历史披露与修订链；数据达标后冻结现金流任务并跑 CPU 基线。暂缓多 Agent 自动因子和图模型，因为当前数据不足以做可靠对照。界面必须保留截止日、证据与数据状态，导出复用同一快照。顾问另发现新 HTML 漏列安装包资源，已经修复并检查 wheel。

## 实际改进

- 新增 `/research`：选择日期、切换现金流／资本开支／利润、查看季度图表、逐项打开原始事实与公式、下载完整 JSON。
- 图表明确区分直接披露和计算待复核，缺失不填零；Q4 继续需要核查跨披露修订与范围，不自动批准成原始事实。
- 日期或密钥一变，隐藏旧结果并禁用导出。取消旧请求并检查请求代次，避免慢响应把旧日期数据放回新页面。
- 新 API 沿用身份控制，只开放登记的公开样例；参数不能选择文件路径或私有案件。不新增模型调用、自动抓取或费用。
- 输入指纹加入公司、财年与研究日期；另记软件和季度规则版本。界面说明指纹不是结果正确性或历史版本保证。
- 新增 [项目用途与技术介绍](../12-project-story-and-technology.md)，按用途、企业问题、解决机制组织。核查 ColPali、Time-MoE、AlphaForge、R&D-Agent-Quant 的正式出处，区分已有基础、计划和研究。

技术取舍：复用现有 FastAPI、原生网页和季度计算模块，没有为图表另建一套计算。研究页只读，信用复核状态机与 `cash-debt-review-3` 保持原语义。季度规则单独记为 `calendar-quarter-2`。

## 如何验证

- **113 项 unittest 全部通过**，其中本轮新增 10 项：公告日／次日、空证据与新鲜度、推导状态、网页视图与 CLI 一致、输入指纹、认证、公开样例边界及非法参数。
- **15 项财务控制回归通过**：仍为 1 个官方参考与 14 个合成扰动，不是模型准确率。
- 页面 JavaScript 语法、Python 编译、文档文件链接和差异格式检查通过。
- 浏览器实际验证：首次公告当天没有值；上半年只有两季；修改日期后旧结果隐藏；切换指标后 Q4 资本开支为 17,079，原值为 64,551 减 47,472，持续标为待复核。
- 实际点击下载上半年快照，文件日期为 2025-01-30，与同日期 API JSON 逐字段相等，没有后续季度来源。
- 桌面 1280px 与窄屏 497px 检查。窄屏发现日期输入与按钮拥挤，调整为按钮单独一行后复查；内容宽为 482px。截图：[桌面](../images/quarterly-research-desktop.png) / [窄屏](../images/quarterly-research-narrow.png)。
- 顾问只读审查发现安装包漏资源，修复后构建 wheel 并确认含 `creditlens/research.html`。项目虚拟环境缺 setuptools，首次构建失败；改用已配置内置运行时构建成功，没有修改系统环境。未验证独立安装后的样例路径，仍要求从仓库根目录运行。

## 局限与下一步

当前仍是一家公司一个财年，网页来自当前抓取，未建立历史首次披露和修订链；没有实时行情、真实模型预测、训练或投资收益。新的季度页还没有与审批记录建立自动关联。浏览器未做网络故障注入、完整键盘和跨浏览器测试；现有 API-key 也不等于机构 SSO 和生产安全验收。

下一轮重点是数据版本契约：首次披露、当时最新、今天修订三个视图；保留 accession／原始文档、可得时间、抓取时间、口径和修订关系。先让旧快照可重建，再扩大公司和年份。当前无需租 GPU。
