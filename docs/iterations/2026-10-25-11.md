## 企业任务与选择理由

投研与风险分析人员需要先判断识别出来的财务数据是否能用于后续计算。上一轮三处金额与相邻列的美元符号混在一起；如果直接挑出与参考答案相同的数字，看似修好了，实际上无法证明没有丢掉负号或选错列。本轮既研究更细的坐标，也测试图像轻微变化是否会改变结论，最后让使用者逐项查看对照。

岗位、企业痛点与竞品依据沿用 2026-10-25 的[产品调研](../01-product-and-career.md)、[文档智能方案](../08-document-ai-and-governance.md)及[独立建议](../research/2026-10-25-advisory-02.md)。对应金融文档处理、模型评测、错误分析和工程交付能力。RapidOCR／PaddleOCR 提供识别组件，CreditLens 补充财务证据检查、拒绝理由和复核流程。本轮未新增招聘市场统计、客户访谈或竞品排名，也没有节省工时的真实企业验证。

## 做出了什么

字词实验保留同一轮的行结果与字词结果，六页父行输出哈希与原基线相同。原行级为 39 项一致、3 项不足；字词位置方法为 42 项一致，只有原来的三处串列状态发生变化。模型仍看完整图片，不接收金额或参考框；字词选择依据位置，不根据期望值挑子串。

独立审查发现：如果一条重叠的原始行没有字词框，它可能被遗漏，造成错误放行。现已修复，并加入字符完整性、相关父行、邻近数字／符号碎片、低分与多候选保护。字词分数不作为校准概率，判定沿用父行分数。[方法、结果与局限](../research/2026-10-25-word-evidence.md)

图像退化实验在推理前固定两页和四档参数，每档检查相同的 20 项事实。原图与 JPEG 各 17 项一致、3 项不足；轻度模糊与降对比度各 18 项一致、2 项不足，均无明确冲突。轻微退化改变了苹果一处检测分组，不能据此推广“模糊更好”。全部 80 项条件结果保留，不拼接各档最好成绩。[完整实验](../research/2026-10-25-visual-robustness.md)

新增 `/experiments` 页面：查看三种方法与四种图像条件的完整汇总，按公司和事实追查，展开父行与失败说明，导出完整对照 JSON。`/api/experiments` 使用现有鉴权，只读取保存的公开实验，不运行模型或批准事实。API 核验发布清单哈希、来源、页与事实完整性、条件参数、计数及转移；数据不一致返回 409，缺失返回 503。

审查同时修复了基线二次读取的快照竞态、缺页未检出、退化参数和原图选择校验遗漏。沿用 `.gitattributes` 的 LF 约定，修复本机已有工作文件的行尾差异，避免相同文本因 CRLF 导致冻结摘要失配。原始实验内容与 Git 中基线字节保持不变。哈希清单支持发现误改或混用，不是防管理员篡改的签名。

## 实际验证

- 合并后本地 **168 项 unittest 全部通过**，含 15 个既有财务控制场景；本轮新增 34 项。合成规则样例不计入真实 OCR 成绩。
- 主开发和独立顾问分别读取本地完整 OCR，复算 42 项字词事实与 80 项退化条件结果；逐字段与公开记录一致。未因界面接入重新运行模型。
- API 测试覆盖鉴权、模拟身份不能绕过、只读、无缓存、篡改／缺失拒绝，以及报告与来源失配。
- 1280px 桌面与 497px 窄屏检查公司、事实、条件切换及父行展开；窄屏内容宽 482px，无横向溢出。输入访问密钥会清空旧记录并禁用导出。
- 实际浏览器下载 JSON 与同次 HTTP 响应逐字段一致。软件编译、页面 JS 语法与本地文档链接检查通过。
- CI 增加 Pillow 依赖，确保图像变换的两项测试也运行；OCR 模型推理仍为本地离线实验，不由轻量 CI 重跑。完整键盘、跨浏览器、网络故障注入及生产负载尚未验收。
