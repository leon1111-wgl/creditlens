# 第 12 轮：把实验页面改成简洁的业务工作台

日期：2026-10-25。用户认为上一版视觉风格过于模板化，明确要求 Times New Roman，并参考腾讯或飞书页面的感觉。本轮改动范围是 `/experiments`，模型、数据、API 和实验结果没有改变。

## 改了什么

旧页使用浅绿色背景、绿色大卡片、34px 提问式标题和英文装饰文字。改版采用白底、浅灰导航、蓝色操作按钮与清晰表格：左侧放项目导航，顶部标明所在页面，主体直接呈现实验结果和核对操作。

主标题为 24px，分区标题 18px，正文和表格 15px，辅助信息 13px；窄屏标题降为 22px。字体使用本机 Times New Roman，中文回退到 Songti SC／SimSun；没有下载或分发商业字体。中文不是由 Times New Roman 绘制。表格数字对齐，输入框和按钮统一尺寸，保留键盘焦点、表单标签和状态播报。

视觉组织参考 [腾讯 TDesign 布局](https://tdesign.tencent.com/design/layout)与[飞书多维表格视图](https://www.feishu.cn/hc/zh-CN/articles/360049067931-%E4%BD%BF%E7%94%A8%E5%A4%9A%E7%BB%B4%E8%A1%A8%E6%A0%BC%E8%A7%86%E5%9B%BE)（2026-10-25 查阅）。实现仍是项目原有 HTML/CSS，没有引入腾讯或飞书组件库、标志及品牌素材。外观参考不等于官方产品或官方集成。

实验范围与失败状态继续可见：已知位置开发样例、合成退化、只读结果、人工复核。没有借视觉改版把 42/42 改称通用准确率。企业任务与岗位依据沿用同日[第 11 轮](2026-10-25-11.md)，没有新增客户或市场结论。

## 怎样确认可用

- 浏览器实测桌面 1366px 与窄屏 497px；窄屏内容宽 482px，无横向溢出。
- 检查公司和图像条件切换；访问密钥改动仍清空旧数据、禁用导出，重新载入恢复结果。
- 实际下载的 JSON 与同次 API 逐字段一致。数据来源、字段规则和导出内容没有因改版改变。
- 检查字体声明及计算字号；本机存在 Times New Roman 与 SimSun 字体。其他操作系统的具体字体回退尚未逐一测试。
- 独立顾问静态核对控件、语义和原交互逻辑，无阻塞回归；采纳侧栏纵向滚动建议，避免较矮桌面窗口中内容不可达。
- 页面 JavaScript 语法、本地文档链接检查通过。不新增仅检查 CSS 实现细节的测试，也不重跑 OCR 实验。
