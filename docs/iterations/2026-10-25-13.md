# 重跑模型时，不再覆盖已经验收的实验

日期：2026-10-25，Asia/Shanghai。本轮围绕一个完整任务：开发者按照说明重跑三组文档实验，能够核对新旧结果，同时保留已有工作台和原页预览。

## 企业问题与本轮选择

分析员或模型验证人员需要重现一份研究结果。重新运行程序不应把正在展示的依据悄悄换掉；遇到变化时，也不能只比较“一致项有多少”。金额没变但位置、符号、单位、原始识别结果变了，同样需要调查。

本轮复用 2026-10-25 已登记的[岗位与产品调研](../01-product-and-career.md)、[文档智能与治理方案](../08-document-ai-and-governance.md)及[平台设计](../11-financial-research-platform.md)。招聘主线仍是金融数据质量、真实模型实验、可追溯工具与工程验证。Docling、ColPali 和 FinQA 分别提供结构解析、页面检索与数值推理的方法参考；本轮没有新增市场调查，也没有把这些工具的能力写成项目成果。

实际发现三个实验脚本默认会把新报告写回已冻结的 `artifacts/`，其中一个还会重新生成网页正在使用的原页图。即使结果数字相同，时间戳等变化也会让冻结清单失配；原页字节变化则会使预览被拒绝。因此先修复复现入口，再开展新公司材料实验。

## 本轮实现

- 三个实验的报告、完整 OCR 和新页图默认进入本地 `.run/reproductions/`，不会修改已发布记录。
- 运行前检查输出位置、目录别名、硬链接以及报告／页图／输入目录重叠，危险路径在下载或模型加载前拒绝。显式准备原页预览时，只接受登记摘要匹配的图片；已有相同文件保留，已有不同文件拒绝覆盖。
- 增加只读对照命令，按公司、页、事实和字段比较公开证据，区分结果或证据变化、运行记录变化和无效输入。完整原始 OCR 不在公开报告里，因此另行读取本地输出复算，不能用摘要相同替代原始文件核验。
- 更新 README、模型操作说明和历史实验的当前复现入口；[完整操作步骤](../16-experiment-reproduction.md)说明怎样重跑、读结果、准备预览与人工审查新版本。

两条实现分支分别负责路径保护和对照工具，研究分支负责独立检查。顾问建议补齐完整输出目录隔离、输出与输入重叠保护，修复对照器固定阈值及清单二次读取问题；主开发检查后采纳。下一批未见公司、跨页表格与图表任务已形成[冻结与评分建议](../research/2026-10-25-advisory-04.md)，本轮没有相应新数据或成绩。

## 验证与发布

主分支依次运行三条默认命令和对照 CLI，使用已固定权重在 CPU 上真实推理。行级仍为 39 一致／3 不足，字词级 42 一致；两页四档分别为 17／3、18／2、18／2、17／3，没有冲突项。这些是已有样例的复现结果，不是新增识别成绩。

对照 CLI 退出 0，三份候选报告均为 `matched`：公开语义字段和证据摘要无变化。行级、字词、退化报告分别有 7、8、9 项运行记录变化，主要是时间、耗时及字词 runner 的实现哈希；这些变化完整列出，未掩盖为“逐字节相同”。

主开发与顾问各自读取本次 20 份完整 OCR／WordPage、14 张候选图片，核对摘要并复算 42 项行级、42 项字词和 80 项退化条件结果，逐字段一致。重跑前后 7 个冻结文件和 6 张旧预览的字节哈希相同，实验 API 的 JSON 相同，六张图片 HTTP 返回字节与原登记一致。服务重启后 `/health` 返回 0.7.1，原实验 API 继续保持一致。

全仓本地 197 项 unittest 运行：196 通过、1 项因 Windows 文件符号链接权限跳过。目录 Junction、硬链接、禁止输出目录、输入／输出重叠、总计数相同但证据变化、错误汇总及导出保护均已实际测试。另通过 Python 编译、文档链接和实验页脚本语法检查。工作区的历史 CRLF 差异在确认与已提交内容仅换行不同后恢复为登记的 LF 字节，没有刷新清单掩盖差异。

主开发追加发现对照导出在 `.run` 整体指向发布目录时可能接受新文件，已改为复用统一路径保护并补目录别名回归。顾问复核最终实现和完整输出，无阻塞问题。简历已补复现工程证据并保留范围限定；[公开核验摘要](../../artifacts/reproduction-verification.json)只保存结果和摘要，完整原始材料仍留本地。

发布与远端 CI 结果在实际完成后登记。

## 限制与下一步

本轮重跑仍是微软、苹果的六页开发材料，不新增独立样本，也不是泛化评测。图像退化是合成处理，不是真实扫描件。路径检查用于防止误写，不是可抵御并发文件系统修改的操作系统沙箱。对照命令不能证明一个报告声称的模型确实运行过，也不能验证未提供的完整 OCR 或图片字节。

下一步按顾问提出的任务契约登记新发行人材料，区分已知位置迁移、跨页证据集合与图表近似读数，冻结公司分组、参考答案和评分规则后再运行。没有新增训练、GPU 租用、付费 API 或企业部署。
