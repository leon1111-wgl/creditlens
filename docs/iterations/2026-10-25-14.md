# 新公司文档核对：修正参考坐标，保留年份规则的失败

日期：2026-10-25，Asia/Shanghai。本轮服务分析员与模型验证人员，完成“换一家公司的材料，检查现有方法，再把失败交给人查看”的任务。

## 为什么做这一轮

此前规则在微软和苹果的六页材料上开发，仅重跑旧案例不能说明换公司后仍然可用。本轮选 NVIDIA 官方年度 PDF 的资产负债表与现金流量表，先固定参考与规则，再实际运行。岗位和企业需求沿用同日[调研](../01-product-requirements.md)：金融数据口径、文档理解、模型验证和可追溯工程。Docling、ColPali、FinQA 的结构解析、页面检索和计算任务仍各有分工，本轮没有声称实现它们的全部能力或新增市场访谈。

独立顾问核对了官方 IR 与 SEC 原始记录，发现包装 PDF 和底层 10-K 的日期不能混用，往年比较列也不能当成往年当时版本。这些发现直接进入数据契约：包装文件日期未知、底层提交日单列、禁止自动用于历史时点任务。完整证据见[顾问报告](../research/2026-10-25-advisory-05.md)。

## 实现与验收

本轮复用三个隔离分支。文档分支交付冻结协议与通用坐标修复；实验分支建立 NVIDIA 参考并交付保存 OCR 后重新评分的工具；研究分支分别审查日期、参考几何及结果。主分支完成 API、页面、原页预览、集成验收。

### 首次运行发现的参考问题

参考与运行规则在提交 `297ea58` 冻结后，实际在 CPU 上识别两张无标记整页图片。逐项查看失败发现参考框整体错位：PDF 可见区域原点是 `(9,9)`，提取器却按零原点换算。数值清单和整页肉眼检查没有发现这个问题，原参考验收确有遗漏。

首次报告、清单、参考、原始 PDF、图片和完整 OCR 都保留；[尝试台账](../../artifacts/document-transfer-attempts.json) 标记 `invalid_reference`，首次计数不作模型质量结果。修复使用 MediaBox 与 CropBox 交集进行一般坐标转换，未按 OCR 输出移动框。审查还发现裁掉负号后可能保留正数，最终对完全或部分裁切的非空白字符、不可读空字符一律拒绝；不支持恢复被裁掉的数字。旋转、尺寸不一致和异常边界同样拒绝。

主开发和独立顾问分别用 PDFium 原生页面到像素变换核查 88 次参考区域、176 个角，最大偏差 0.494 像素，落在整数像素取整范围；这些共享表头区域不是独立样本。旧微软／苹果六页逐词内容与坐标完全不变。见[几何核验](../../artifacts/document-geometry-verification.json)及[顾问记录](../research/2026-10-25-advisory-06.md)。

### 修正后仍然保留的失败

修正版参考在 `bae898a` 冻结。财务值、期间、页码、图片、模型与评分规则保持不变，复用首次完整 OCR，仅重新评分。重评分脚本先验证原始文件和完整输出，还用旧参考复算首次报告，再生成新候选；原推理时间与评分时间分别记录，耗时注明来自首次推理。

| 方法 | 完整事实一致 | 明确冲突 | 证据不足 |
|---|---:|---:|---:|
| 行级核对 | 0 | 0 | 16 |
| 字词核对 | 0 | 0 | 16 |

**16 个金额字段均一致，不等于 16 项事实通过。** 金额、完整日期、单位、行标签及适用分区能对上，年份字段全部不足。行级识别把 `Jan 26, 2025` 作为一行，无法单独确认年份框；字词级识别到了 `2025`，但现有保护规则把附近的 `26,` 当成需要检查的数字片段。现有规则在这种表头上过于保守，系统没有放行。这些事实共用四个页内日期表头，不能当成 16 个独立失败样本。

这批材料已经观察，v2 是诊断结果，没有形成未见公司盲测或泛化成绩。本轮不改阈值、不删失败项，也不将参考修复包装成模型提升。主开发与顾问从完整输出复算 v1/v2 两种方法共 64 项事实结果，逐字段匹配；公开报告只保留必要证据，完整原文仍在本地。

### 采纳、暂缓与仅完成设计

- 采纳：未知包装日期单列、非历史时点数据合同、保留 v1、一般坐标转换、裁切字符拒绝、同一 OCR 重评分、图片与快照版本绑定。
- 暂缓：同一行完整日期与年份的关联规则。下一轮需只调整年份确认路径，保留金额的数字碎片保护；先建立错日期、错列、缺年份等反例和规则版本，再拿另一发行人验证，不能追调本轮分数。
- 仅完成设计：跨页任务需返回表头、续表及脚注的完整页集合；图表明确标注值和近似估读分开设误差与拒答条件，沿用[任务契约](../research/2026-10-25-advisory-04.md)。尚无这两类模型运行结果。

## 边界与下一步

这一轮是固定位置的新发行人迁移检查；参考由项目整理并经代理复核，没有独立双人人工标注。模型仍只识别图片，财务口径与证据检查由程序完成。新的来源包不接入信用案件或历史回测，不能因为多了一家公司就宣称预测数据已充足。

下一步先补日期关联规则与参考几何验收，再扩大按发行人分组的评测材料；跨页、单位脚注和图表近似读数分别推进。没有新增模型训练、付费 API、GPU 租卡或企业生产部署。本轮新增的 NVIDIA 仍是独立文档诊断参考，不是第三家可审批信用案件。
