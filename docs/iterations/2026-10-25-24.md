# 第24轮：金额相同，还要检查证据是否完整

日期：2026-10-25。版本：v0.16.0。

## 为什么做这一组改进

投研和风险人员拿到一个金额时，需要知道这个数属于哪种币种、是否漏了负号，以及文字定位能否回到正确行。只比较数字字符会掩盖问题：`¥1,234` 与登记的美元 `1,234` 数字相同，但不能直接用于同一计算。

本轮沿用 2026-10-25 已核验的[产品需求](../01-product-requirements.md)、[论文与开源调研](../02-open-source-and-papers.md)和[文档智能设计](../08-document-ai-and-governance.md)。岗位主线仍是金融文档处理、模型验证和可维护后端；RAGFlow、Docling 等相关方案提供文档解析与检索能力，本项目仍需实现明确的财务口径和证据检查。这里是基于公开材料的设计判断，没有新增客户访谈或竞品性能比较。

## 本轮完成

独立顾问复现了三个合成反例：金额父行框移动而字词框不动；把完整金额改成其他币种；在金额旁边放入没有词框的独立负号。旧规则均可能判为一致，因此新增检查必须覆盖已经判为一致的金额，而不能只处理失败项。

`evidence-guard-1` 先按位置选候选，再检查完整金额语法、正负号、币种标记、父词位置、全文守恒及固定邻域。金额外的字段不改动；保留原始判定，也不会把旧不足自动升级成通过。两处合法的同父行拆分美元符号采用明确关系，不能随意丢弃邻近文字来匹配参考值。

诊断逐项重算公开证据和固定控制，绑定来源文件、参考、规则实现和输入摘要。API 按现有身份检查返回只读记录；缺文件、篡改或版本不匹配分别返回可识别错误。页面新增第四个任务模式，展示五种规则结果、每项原因和完整记录；合成控制与实际保存材料分开统计，完整 JSON 按需展开。

三个既有隔离分支分别交付核心与测试、诊断与固定控制、独立审查；主分支负责接口、页面、实际下载和发布核验。详见[技术说明](../27-evidence-integrity.md)和[顾问审查](../research/advisory-15.md)。

## 设计取舍、限制与下一步

采纳：对所有金额执行新守卫；完整输入和公开片段检查分开记录；参考值不参与候选选择；固定控制完整计入分母；实际调用和页面导出分别验收。

暂缓：旧 `TransferManifest` 的重复 PDF 登记及旧 OCR 转换器对非有限原始四边形的处理，由后续版本修复。本轮只检查归一化 `WordPage`，不修改旧冻结规则和结果，也不声称覆盖原始坐标全部异常。

跨页表格与图表任务继续采用[独立审查中的冻结方案](../research/advisory-15.md)：先登记许可、页面连接关系、单位、合并单元格与图例，以及缺页、续表错列和近似读数的失败标准，再比较文字、结构化表格和页图路径。当前仅完成设计，未运行视觉模型对照，也没有独立人工金标准。

下一轮优先修复上述输入层问题并补充独立人工题；有合法新材料后再开展跨页或图表实验。当前改进完全在 CPU 上完成，不需要租训练服务器。
