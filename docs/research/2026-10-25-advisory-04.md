# 先保证安全复现，再冻结未参与开发的文档任务

日期：2026-10-25，Asia/Shanghai。审查起点：`b70b2903189b44143b0afe24bab3673c6c766527`，v0.7。研究分支只新增本报告，主工作区只读。本轮建议服务于“别人按照说明重跑，已有演示仍然可用，并能看清新旧结果差在哪里”。没有新增客户访谈、市场统计或保留集成绩。

## 当前最应修复的复现问题

三个 OCR runner 在本轮起点默认将报告写回 `artifacts/`；其中基线 runner 还会写入网页预览正在读取的 `.run/document-ai/`。即使给报告指定安全的 `--output`，新的渲染文件仍可能覆盖原页，导致已有预览因哈希不符而无法打开。操作说明与实验说明也有使用危险默认值的旧命令。只改 README 不够，应让命令本身采用安全默认值。

本轮已分工：一条实现分支负责输出路径保护与独立复现目录，另一条负责只读对照 CLI，主分支统一说明并运行完整链路。新报告、完整 OCR 与新页图应进入 `.run/reproductions/` 等隔离位置，已冻结报告、清单及现有网页预览保留。下面是验收建议，实际完成情况以合并后的制作报告为准。

| 验收内容 | 怎样检查 |
|---|---|
| 旧结果继续可用 | 重跑前后比较冻结的六份报告/配置、发布清单以及现有预览 PNG 的字节哈希；现有实验 API 的 JSON 与原页 API 仍能读取原结果。不能只检查 `git status`，因为页图在忽略目录。 |
| 路径保护先于副作用 | 显式将报告、完整 OCR 或页图输出指向冻结文件、旧预览或输入目录的危险组合时，须在模型加载、下载、目录创建与写入前拒绝；同时检查解析后的路径别名，避免只比较原始字符串。 |
| 重跑形成独立证据 | 新报告能定位本次完整 OCR、页图、模型/配置、来源及执行环境。三条命令能够依次运行，后两条读取本次准备的页图，不能误接另一分支运行中的文件。 |
| 对照逐项进行 | 按发行人、页、事实、字段、图像条件对齐，检查缺失与重复，比较文字、符号、区域、分数、父行与拒绝原因。39/3、42/0 或总数相同都不足以证明复现。 |
| 易变信息单列 | 时间戳、耗时、平台和包版本变化与证据变化分开显示；不得用宽泛的“忽略元数据”隐藏输入、规则、模型、原始 OCR 摘要或状态变化。 |
| 对照不改参考 | CLI 不更新冻结报告或清单。发现差异应保留两个结果并解释原因，不能刷新 manifest 来消除差异；新实验正式发布仍需独立审查与版本记录。 |

对照应分成两层说明。公开报告 CLI 可以验证公开证据、来源绑定和逐项状态，并明确哪些完整 OCR 或图像未检查；主开发再读取本次保存的完整 OCR/WordPage，核对摘要并重算字段。只有执行了后一层，才写“本次完整模型输出已复算”。跨系统结果即使字段判断相同，也可能不是逐字节相同；二者分别报告。脚本重跑证明当前案例的可复现性，不新增独立样本或泛化成绩。

## 下一步保留集服务什么任务

沿用同日 [岗位与业务调研](../01-product-requirements.md)、[文档智能方案](../08-document-ai-and-governance.md) 和 [平台方向](../11-financial-research-platform.md)。企业任务仍是从财报材料中找到可用证据、核对口径、追查失败并交接研究结论。现有六页适合定位串列问题，不能证明换发行人、续表或图表后仍然可靠。

下一批数据不按“收集更多 PDF”组织，而按三个可评分任务组织：

1. **已知位置的迁移检查。** 给定页和登记区域，对未参与本项目规则开发的发行人核对金额、年份、期间、数量级和行标签。用于判断现有规则是否只适合微软/苹果；仍是已知位置任务，不改称全报告抽取。
2. **跨页表格与附注关联。** 给定文档和问题，找到起始表头、续表行、单位脚注及相关正文，返回完整证据集合；单独检查漏页、混年份和合并口径。若已给正确页，分数只代表页内任务；全报告找页能力另外评测。
3. **图表与文字交叉核对。** 分开标注图例/坐标轴识别、图上明确标注值、近似读数和正文中的精确值。近似读数预先约定允许误差及拒答条件；无刻度或不可读的图不能强造精确答案。

方法参考继续使用已核验的 [Docling 官方仓库](https://github.com/docling-project/docling)、[ColPali 正式论文](https://proceedings.iclr.cc/paper_files/paper/2025/file/99e9e141aafc314f76b0ca3dd66898b3-Paper-Conference.pdf) 和 [FinQA 原论文](https://aclanthology.org/2021.emnlp-main.300/)。它们分别帮助考虑文档结构、相关页面检索和可执行数值推理，不能互相替代评分，也不构成本项目已复现它们的证据。本轮复用既有同日调研，没有新装框架或引用原论文成绩作为项目成绩。

## 怎样冻结，而不把开发样例改名为保留集

建议先登记一小批候选，再确定能完成独立核查的任务数量。首批可以以“至少三个新增发行人用于适配、另外三个发行人留作保留”为规模起点；这是工作量建议，不是样本充分性的统计结论。微软、苹果及已调过规则的材料继续归入开发集。不同年度、修订版、相同报告拆页、图像退化副本都随原发行人/文档分组，不能随机拆到开发与保留两边。

每份材料优先取监管机构、交易所或发行人官方网站的原始披露。登记文件 ID、发行人 ID、文档类型、官方 URL、公告日期与时间精度、财务期间、首次抓取时间、原始字节哈希、版本/更正关系、语言、是否数字 PDF 或真实扫描、许可依据及可公开范围。物理页号和印刷页号分别记，渲染参数与图像哈希另记。当前网页下载不自动证明历史首发版本。

每个任务至少登记任务 ID、文档及页集合、任务类型、模型可见输入、正确证据位置、所需字段、单位和期间、答案或明确不可回答的原因、计算公式、允许误差、标注者与复核状态。跨页任务需列出所有必要页；单页找到正确数字但缺少单位脚注不能算完整成功。已有标注框是否给模型必须在输入契约中写清楚。

冻结时保存任务清单、发行人分组、评测规则、版本和哈希；规则开发者不能拿保留集答案挑阈值、改空间规则或选择最佳预处理。先锁定开发集上的参数，再跑一次保留集并保留全部失败。如果看到保留集后需要改方法，该批材料转为已观察评测记录，下一次结论应另用未参与修改的材料。公开保留集只能证明未参与本项目调参，不能证明预训练模型从未见过其原文。

参考答案应独立于被评模型生成，并保留复核争议。若只有一人整理，应标为“单人参考，未独立复核”；两个程序或两个同源模型一致不等于双人独立标注。原始文件及完整页图按许可留在本地，公开必要任务、登记信息和可复现获取方式；不能因来源权威就默认可无限再分发。

## 评分和发布边界

按任务分别报告：证据页完整率、字段/单位/期间核对、数字误差、错误放行、拒绝与覆盖，以及预先规定的人工复核去向。图表估读不能与表格精确值混成同一准确率；共用表头和同页变体不是独立样本。样本较小时展示每份文档的结果和失败，不给没有统计依据的行业级结论。

本轮尚无新发行人保留集、跨页表格或图表任务的运行结果，也没有真实扫描件泛化结论。今日新增复现脚本、路径保护和对照报告可作为工程交付；新增模型能力须等待上述任务真正冻结、运行和审查后再写入项目说明。
