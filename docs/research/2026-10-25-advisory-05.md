业务、岗位和竞品判断沿用同日 [岗位调研](../01-product-and-career.md)、[文档智能方案](../08-document-ai-and-governance.md)、[平台方向](../11-financial-research-platform.md) 与 [上一轮顾问意见](2026-10-25-advisory-04.md)。这一步为分析员提供可追查的新材料失败记录，并不新增企业访谈或市场结论。Docling 的结构解析、ColPali 的页面检索和 FinQA 的数值推理仍是不同任务；当前实验不声称实现了这些完整能力。

## 来源登记应怎样落到代码

建议迁移数据使用独立来源契约，不因旧 `CasePack.Source.published_at` 必填就补一个假的 PDF 日期。该旧字段参与可得日期筛选，也在界面直接显示为披露日；把抓取日期塞进去同样会改变语义。

最少登记：`underlying_filing_date=2025-02-26`、底层 accession 与 SEC 链接、`wrapper_publication_date=null`、`source_date_basis=wrapper_publication_unknown`、实际 `retrieved_at`、本次原始文件字节哈希、`point_in_time_eligible=false`。如需保存索引时间，使用明确的 `acceptance_as_displayed`，不擅加时区。ARS 记录作为另一个材料的旁证，不能覆盖包装文件日期。

本包只服务视觉迁移实验，不自动注册进信用案件、季度历史快照、因子预测或回测输入。将来若需要历史研究，应为有正式提交日期的原始 10-K 文件建立独立版本和可得规则；当前包装文件不能替代那条证据链。

同一 10-K 的 Note 1 还说明部分往年余额已按本年列报重分类。登记的往年列应称为“FY2025 文件中列示的比较值”，不等于此前年度当时可见的版本；可记录 `comparative_values_as_presented_in_fy2025=true`，避免后续把比较列直接拼成历史回测数据。

许可方面，未核实到该 PDF 的开放再分发许可证。当前 [NVIDIA 官网条款](https://www.nvidia.com/en-eu/about-nvidia/terms-of-service/) 第 3、4 节提供有限内部使用条款并保留材料所有权，不构成全文开放许可；条款范围也不应被扩写成对所有第三方副本的法律结论。登记为“未确认开放再分发授权”，原 PDF、整页图和完整 OCR 留在本地，公开必要数值参考、位置、哈希和获取方式。项目代码的开源许可证不覆盖原披露材料；商业语料使用和公开整页展示另核许可。

## 冻结与验收建议

1. **冻结参考先于 OCR。** 保存发行人、文件哈希、页集合、全部事实和字段框、财务期间、单位、符号转换、参考建立方式及复核状态。参考来自文本层和人工可视核查时须如实说明；没有两位独立标注者就不能写双人标注。
2. **冻结算法契约。** 绑定现有模型权重、渲染参数、置信阈值、空间规则和代码哈希。新通用 runner 可负责加载和编排，但必须调用相同核对函数，不能为新发行人增加特判、挑预处理或选择较好的输出。
3. **识别与评分隔开。** 模型只看无标记整页图，不接收参考金额或框。完整 OCR 先落盘，再由固定规则选取已知区域并评分；坐标在评分时可见，因此结果仍是已知位置核对，不是端到端抽取准确率。
4. **完整结果绑定来源。** 每页图像和原始 OCR 都有摘要；报告绑定冻结数据集与规则，校验唯一、完整的事实集合，分别重算行级和字词结果及汇总。出现不足或冲突时保留原文、符号和拒绝原因，不能通过改参考或刷新清单隐藏差异。
5. **发布与重跑隔离。** 首次正式结果经独立审查才登记为发布快照；后续默认写入隔离复现目录，不覆盖参考、已发布报告、清单或原页。工作台载入只读结果，身份与数据集切换须清除旧状态，导出当前记录；不能点击页面就意外跑模型。
6. **按预先任务报告。** 分开列出发行人、页数、事实数、字段失败、全字段一致／冲突／不足和覆盖。并排展示行级与字词方法，但不只挑较高结果。共用表头和同页多事实相关，不能把它们当作大量独立公司样本。

本轮可称为“未参与本项目规则调整的新发行人已知位置迁移检查”。即使全部一致，也不能称模型预训练未见、行业泛化验证、通用多模态理解、真实性鉴定、预测增益或真实银行验收。若看过结果后修改规则，本批应标为已观察实验，新的迁移结论另取材料。
