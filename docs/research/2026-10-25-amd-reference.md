# AMD 新发行人参考：先定材料和口径，再运行模型

日期：2026-10-25。本文只记录参考准备，不包含 AMD 的 OCR 输出或模型成绩。识别实验须在参考、算法与配置冻结后运行。

企业分析员拿到新公司的材料时，不能假设旧公司的表格布局和财务口径仍然适用。本实验选 AMD，是因为它与 NVIDIA 同属半导体行业，也使用周历财年，适合在保留业务可比性的同时检查新排版。选材发生在模型运行前；没有按识别效果挑公司、挑年份或删难题。

## 来源与时间

原件来自 [AMD 官方投资者关系网站](https://ir.amd.com/financial-information/sec-filings/content/0001193125-26-129106/0001193125-26-129106.pdf)，共 124 页、4,032,484 字节。首次本地下载时间为 `2026-10-25T08:22:40.588016+00:00`，SHA-256 为 `c7dac911d91ed1b38afa3fbf3b3408cbd0c105d1c820a4b6fa15f553e2892187`。

需要分开记录几个事件：

| 信息 | 已核验的事实与适用边界 |
|---|---|
| 原始 10-K | [SEC 索引](https://www.sec.gov/Archives/edgar/data/2488/000000248826000018/0000002488-26-000018-index.htm) 的 Filing Date 是 2026-02-04；Accepted 显示 2026-02-03 18:14:52。两者不是同一个字段。 |

## 运行前固定的题目

固定两张表、最近两财年、七个财务项目，共 14 项事实。资产负债表为物理第 74 页／印刷第 62 页，现金流量表为物理第 76 页／印刷第 64 页。2025 和 2024 两个日期列均分成“December 日,”与年份两行；资产负债表的单位也跨两行。这些结构完整保留，没有为了适配完整单行日期规则而改写。

金额单位为百万美元；以下是文件原始显示值，括号不能丢失。

| 项目及范围 | FY2025 | FY2024 |
|---|---:|---:|
| 现金及现金等价物 | 5,539 | 3,787 |
| 流动资产 | 26,947 | 19,049 |
| 流动负债 | 9,455 | 7,281 |
| 长期债务，扣除流动部分后的净额 | 2,348 | 1,721 |
| 持续经营活动现金流 | 6,493 | 3,041 |
| 整体净利润，包含终止经营 | 4,335 | 1,641 |
| 持续经营购建固定资产现金流出 | (974) | (636) |

现金流表还有总经营现金流 7,709／3,041，以及终止经营分区的另一行资本支出。选择持续经营 CFO 和持续经营资本支出，是在运行前作出的范围决定；重复行用分区的起点和终点区分，不靠金额匹配。净利润在这张表中是整体值，标签和定位说明保留这一差异。本包不提供公司整体自由现金流或混口径现金转化率，也不进入信用审批流程。

物理第 77 页／印刷第 65 页的 Note 2 明确三个财年均为 52 周。FY2025 为 2024-12-29 至 2025-12-27，FY2024 为 2023-12-31 至 2024-12-28，含首尾均为 364 天。同一页说明部分 FY2024／FY2023 数额按本期列报重新分类。因此往年值是 FY2025 文件中呈列的比较数，不是原始 FY2024 历史版本。

预先不计分的内容也有记录：第三个 FY2023 列仍保留在整页图中，但本实验只取最近两年；总 CFO 和终止经营 CFO 不属于所选持续经营范围；终止经营资本支出和流动债务在 FY2024 出现横线，不能自动补零；其余行和非现金资本支出不在固定七项清单内。完整排除理由由构建器的 `EXCLUSIONS` 保存，不能在识别后悄悄调整。

## 参考怎样建立

`scripts/build_amd_reference.py` 读取 PDF 文本层，先确认报表标题、分行日期、年份、单位和分区，再按行标签与列位置读取数值。构建器没有预期金额参数，也不使用模型输出找单元格。点状引导线只能在数值列之前作为排版分隔；数值列内的点不能随意删除，以免吞掉小数点。

两页可见边界、MediaBox 与 CropBox 均为 `(0, 0, 594, 774)`，旋转为零。沿用已有可见页面坐标变换，将原生 PDF 坐标换成左上角原点的点坐标；没有为 AMD 改动旧几何、OCR 或核对规则。正文密集、引导点多、日期跨行和单位跨行都是本实验材料本来的特征。

准备阶段已完成：

- 两张未标记整页图视觉核查；14 项事实的全部金额、年份、期间、单位、行标签和分区区域叠加检查。去重后为 35 个区域，按每项事实展开共 78 个区域。
- 14 个金额框通过原生文本有界提取反查，去除空白后与登记值逐项相同，资本支出括号保留。
- 78 个区域的 156 个角点与 PDFium 原生 `to_bitmap` 转换核对；最大差异 0.5 像素，属于整数像素取整。
- 在未查看 OCR 输出的条件下，原文、金额、财年和几何经过工具辅助交叉复核。参考建设仍由单一流程生成，不称为双人独立标注集或盲测准确率。
- 10 项构建器测试通过，覆盖跨行表头、持续经营分区、重复行、按位置读取变化值、跨列／缺格／多格、错误日期、单位缺失、数值列小数点保护和输出路径保护。测试使用合成 tokens，不是模型成绩。

保存的无标记整页图为 1188×1548 像素，使用 pypdfium2 5.14.0、`render(scale=2)` 与 PNG 输出。页 74 的 SHA-256 为 `83bb47d9e27fc2c84f6dd9d23baa72b08aabbc04533d206472ab4cac437aaec3`，页 76 为 `a007af0a6dac14cede0c28215a2239958cf61be94434005d0cd02c7c4083aa52`。模型只能接收这类无标记整页图，不能接收定位框、参考值或检查用叠加图。

## 重建与公开边界

在仓库根目录、安装现有可选 PDF 依赖后运行：

```bash
python scripts/build_amd_reference.py --download
python -m unittest tests.test_amd_reference -v
```

默认候选写入 `.run/amd-reference/reference-pack.json`，页面与溯源也留在 `.run/amd-reference/`。`--download` 只允许写登记缓存，下载后校验已固定的 PDF 哈希；默认不会下载。公开包为 `data/examples/amd-fy2025-evaluation.json`，内容是最小事实、来源和位置。正式实验清单经核验后另行冻结。

官方可下载不等于允许任意再分发。本实验不将完整 PDF、整页图片、完整文本、叠加图或未来完整 OCR 上传到公开仓库，也未将原始材料标为开放数据许可证。构建器是固定版式参考适配器，不是通用 PDF 抽取器；后续模型的成功、失败和规则适用范围须单独报告。
