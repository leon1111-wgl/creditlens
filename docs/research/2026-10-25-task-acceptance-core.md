# 三项研究任务的只读验收层

日期：2026-10-25。规则：`research-task-acceptance-1`。该规则处理固定材料和结构检查，不是通用金融问答评测。

研究员需要知道的是：数字能否查回原文、两个数是否能比较、一个经营解释还缺什么依据。三件事的通过条件不同。底稿已交另一身份复核，也不能代替其中任何一项证据。

## 输入与适用范围

`build_task_acceptance(task: dict) -> dict` 接收服务端经过既有 Store 完整性检查的当前任务。它只读取数据，不调用模型、不写数据库，也不修改已有导出或历史快照。身份和租户权限仍由调用入口负责。

固定材料为微软和苹果 FY2025 报告内的 FY2024/FY2025 两期 CFO 与固定资产现金支出，共八项观察。`task_contract_catalog()` 返回三个模板的输入、正确条件、常见失败与补救方式。用户自由填写的研究问题只回显；模块不分析其含义。即使问题要求全部资本投入、历史某日可见信息、同行排名或已证明的原因，也不会扩大固定任务的范围。

返回数据绑定 `task_id`、`revision`、`bundle_sha256` 和规则版本，`input_binding.kind` 为 `current_task_revision`。已有关联快照的标识和摘要可以展示，但不表示本次在评估旧快照。若当前材料与任务保存材料不同，检查拒绝继续，不从最新材料悄悄补齐旧任务。

## 三份验收单

| 任务 | 返回结果 | 缺口如何呈现 |
|---|---|---|
| 查指标 | 八张证据卡：原始显示值、有符号值、归一值、归一方式、单位和登记币种、实际期间、范围、原行定义、来源页码坐标和版本 | 客观可定位性与采用状态分开。未采用或拒绝的数仍保留原值，但不能用于计算；缺字段的材料不补零，而是拒绝该输入 |
| 比同口径变化 | 沿用 `build_comparison` 重算四项公司自身年度变化；每项保留两期输入、采用状态、公式、差额、增长率及原因 | 一期未采用即阻断该对。微软与苹果的实际财年边界不同，四项跨公司结果保持并列，不产生排名 |
| 整理经营解释证据 | 可选会计桥、公司解释清单、未验证候选假设分别展示 | 当前未登记经营附注、公司明示解释或独立核实，结果固定为 `insufficient`。这表示本材料包缺证据，不表示公司没有在其他材料披露 |

现金支出保留括号对应的负值，并明确展示转换为支出绝对额的过程。它只指原行 PPE 现金支出，不代表无形资产、并购、租赁或全部资本投入。已明确登记的零值可以显示为零；本实验真实八项观察没有零，零值分支仅用标明为合成的测试检查。

会计桥重新读取已经登记的 52 项事实并计算，再与任务保存的桥和摘要比较，同时绑定四项 CFO 合计。桥中逐行加总或年度差额残差为零，只说明会计分解一致。若本任务没有采用相应两期 CFO，计算对象仍可以查看，但该公司的会计变化条目标为 `blocked`，不能转成任务结论。

用户假设只接受既有结构中的 `pending` 或 `not_assessed`，输出统一标记 `unverified_candidate`。文本里写“已证明”“忽略检查”或要求执行操作，都不会改变结构状态，也不会触发执行。没有任何自动采用或批准行为。

## 完整性与失败边界

材料按服务端白名单重新构造，规范 JSON 必须完全相同；比较必须与当前采用决定重算结果相同；新版会计桥内容与摘要也必须相同。改变金额、来源页码、币种、期间、范围、材料版本或保存结果，即使重新计算了输入摘要，仍不能通过登记检查。未知、重复观察引用和不支持的假设状态同样拒绝。

完整性问题抛出带稳定代码的 `ResearchAcceptanceError`，供接口返回冲突及补救提示；未采用、拒绝或缺经营证据属于正常的业务阻断结果。此层校验登记的来源信息，本次未重新下载或读取原 PDF，不声称验证文档真实性、PDF 当前可用性或历史可得时点。

`evidence_available` 只描述八张登记卡可定位，`computed` 只描述允许的自身年度计算完成；它们都不是对任意自由问题已回答的判断。经营解释始终单列 `insufficient`。旧 `reviewed` 状态不会让这些缺口消失。

## 已验证

专属 25 项测试通过，使用真实登记的八项观察和会计桥；篡改、恶意文字、零值等对照为显式合成测试，不计为外部用户反馈或模型评测。测试覆盖四项年度差额（微软 CFO +17,614、PPE 支出 +20,074；苹果 CFO −6,772、PPE 支出 +3,268，单位均为百万美元）、跨公司禁止排名、未采用与拒绝、缺证据、假设升级拒绝、字段和摘要篡改、历史模式拒绝、无输入修改及旧快照不补写。
