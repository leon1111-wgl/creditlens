# 独立研究建议

这里保存对 CreditLens 产品与实验路线的独立复核。建议先写明核查的代码版本，再说明证据、取舍、验收条件和不确定性。研究建议不自动改变主分支计划，也不等于功能已经实现。

每轮优先回答一个会影响开发顺序的问题，复用注明日期的已有调研。只有影响决策的新结论才补查原始资料；不以论文数量、功能数量或模型大小代替有效成果。报告中的实验门槛是建议，只有经实际运行才能登记为结果。
