# 把收入、现金流与合并范围放到一次核对中

本轮解决一个很具体的问题：研究员想知道某公司某年的经营现金流净额相当于营业收入的多少，却不能只拿到两个数就相除。数字可能来自不同年度、不同公司或不同报表范围。现在将金额及其原文位置做成可选择的证据卡，范围依据单独占一张卡；选错或漏选时保留原因，不补零、不自动借另一任务的资料。

固定任务是微软和苹果的 FY2024、FY2025，共四项。使用同一份 FY2025 年报中的比较列，计算名称为**经营现金流净额占营业收入比例**。它不是销售回款率或收现率，也不能单凭比例认定经营原因、收入质量或持续经营现金流。这里检查不同报表页之间的证据关联，没有实现同一张表跨页续表的自动拼接。

Note 1 复用此前工具辅助登记的合并基础短锚，只能定位到页，没有精确文字框。本轮不补造这些框，也不沿用旧记录中的 `manual_source_review` 字样来声称独立人工确认。范围卡的年度和期间表示当前任务的适用上下文，不表示附注短锚逐字列出了两年的日期。独立人工确认仍为 pending。

四个任务共有十二张角色卡，但只有八个金额事实和两个共享的范围短锚。两年引用同一段合并基础不能当作两份独立佐证，更不能把十二张卡算成十二项人工标注成绩。

`registered_at=2026-10-26` 是本目录登记日期；本轮任务同日查看当前登记版本。既有 `source_published_at` 仍是原包的来源日期登记，不证明当前 PDF 字节在历史时点已经可得。FY2024 数值来自 FY2025 的比较列，不冒充 FY2024 当时版本；历史模式明确拒绝。

## 可复算的选择检查

`build_cross_page_materials(root)` 只返回固定的四项任务、十二张卡、两份来源绑定和限制。`material_sha256` 覆盖除摘要本身之外的整个规范 JSON；没有当前时间或本机绝对路径。读取源包时拒绝重复 JSON 键、非有限值、来源变化及框/期间/单位错绑；组装前后的来源登记变化会阻断返回。

计算由独立的 `evaluate_evidence_selection(task, cards, selected_ids)` 完成。使用 40 位 Decimal 上下文，先计算 `cfo / revenue * 100`，再按 ROUND_HALF_UP 保留六位百分比。零收入、负收入与缺失收入分别保留为问题，不计算本任务比例；负经营现金流可保留带符号结果。

固定的四项预期分别为微软 FY2024 **48.362856%**、FY2025 **48.331701%**，苹果 FY2024 **30.241283%**、FY2025 **26.788190%**。这是描述性财务计算，不是模型准确率或公司间排名。

复演另登记十八项合成控制：缺范围/缺现金流/缺收入、错年、跨公司、重复/未知 ID、零或负收入、合法负现金流、错单位/期间/分部范围、历史模式、未来来源日期、显示值与归一值冲突、无法读取、金额框缺失。修改只发生在内存副本，原包保持不变。合法负现金流是正控制，避免通过“一律拒绝负号”制造表面通过。

检查报告保存每一项的固定预期、输入摘要、实际结果、金额与引用、拒绝原因和检查是否符合预期，所有控制进入分母。验证器重新构造资料并逐字段重放整个报告；保持汇总计数不变也不能掩盖金额、来源、人工确认声明或引用的变动。

2026-10-26 实际复演：[完整检查报告](../../artifacts/cross-page-evidence-checks.json)共二十二项，四项登记披露任务可计算，十八项合成控制中合法负现金流一项可计算，其余十七项拒绝，全部符合事前固定预期。结果预期检查为 22/22，所选引用逐字段保留检查为 22/22，预期拒绝检查为 17/17；三种检查分别统计，不合成“模型准确率”。本分支十四项测试通过，覆盖资料变化、范围锚错绑、期间/单位异常、完整报告重放与安全新文件输出。报告保留全部逐项检查与引用，约 579 KiB，不包含 PDF、页图或完整 OCR。

## 复现与边界

在仓库目录执行：

```powershell
python -m unittest tests.test_cross_page_materials
python scripts/evaluate_cross_page_evidence.py --output cross-page-evidence-new.json
```

脚本只允许在 `.run/reproductions` 直接新建 JSON，存在同名文件就拒绝；不能直接覆盖发布报告或写入原始实验目录。报告发布由主开发复核后单独处理。脚本无网络、OCR、模型或数据库调用，源 PDF 和完整 OCR 不需要留在本机。

这组控制是开发者辅助设计的固定选择检查，独立人工金标准为 **0**。它不验证任意自然语言问题理解、开放式检索召回、模型生成答案，也不证明原文真伪或金融机构生产部署效果。金额卡与附注之间的规则关联保留为可查依据，不升级成自动采用或批准。
