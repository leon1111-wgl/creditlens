# 旧准备记录现在还能用吗

日期：2026-10-26。旧记录通过内部一致性核验，只说明导出的状态、摘要和关联符合保存时的契约。后续登记资料可能已经调整，也可能暂时无法读取。两件事应分开显示。

`assess_preparation_applicability` 接收离线核验器的结果，读取当前登记，并比较完整材料绑定与处理规则版本。它不修改旧导出、数据库或当前清单，不读取 PDF、页图或原始 OCR。

| 当前结果 | 含义 | 是否可接着做内容核对 |
|---|---|---|
| `matching_registration` | 登记绑定摘要仍相符 | 还必须历史页集、逐页图像和事实登记与当前一致，处理版本相同，且历史尝试为 `prepared_not_indexed` |
| `document_registration_changed` | 选定文档的 PDF 身份声明、参考包或页面登记改变 | 否，先复核变动并建立适当的新记录 |
| `inventory_changed` | 全局清单或登记集合改变，选定文档登记本身未改变 | 否，保守复核；这不等于该 PDF 有了官方修订 |
| `document_not_registered` | 当前清单有效，但已找不到这个文档 ID | 否；不能据此推断公司没有披露 |
| `registration_unavailable` | 清单缺失、损坏、绑定失效或检查过程中变化 | 无法判断；旧导出的核验结果仍保留 |

历史上待修正的尝试，即使当前清单匹配，也保持待修正。如果只有程序声明的规则版本改变，材料状态仍显示匹配，但原因说明版本不同，不能继续。这避免把代码升级说成 PDF 发生修订。

除了摘要，还会直接核对历史页码集合，以及每页声明的来源、图像摘要与事实 ID。一个导出可以被人重新计算摘要，使删页或更换图像声明后的内容仍然自洽；离线核验无法从不透明的文档摘要还原原页集。本次当前检查能发现这些明文字段与实际登记不符，返回 `historical_page_set_mismatch` 或 `historical_page_inventory_mismatch` 并阻止继续。这仍不等于证明作者身份或文件真实性。

输出包含任务与尝试编号、历史导出及报告摘要、历史和当前的材料绑定摘要、变更字段和固定原因代码。没有当前时间字段；同一输入与同一登记应得出相同结果。页面所说的“当前”是本次检查，不是持续监测。

当前登记在比较前后各读一次，两次不一致或确认读取失败时丢弃可能过时的当前绑定，返回不可判断。这不是操作系统锁，也无法保证检查结束后资料仍然不变，或发现所有先变化再恢复的情况。

17 项隔离测试已通过，覆盖同一登记、旧待修正、无关清单调整、增添其他文档、选定参考包与 PDF 身份改变、文档移除、缺失与坏文件、规则版本变化、两次读取之间变化及旧输入保持原样。另实际构造了自洽删页和更换图像／事实 ID 的导出：离线核验保留其自洽状态，当前适用性拒绝继续。全部测试修改临时材料，真实冻结清单保持不变。独立人工金标准和新增模型推理均为 0。

`ready_for_content_review=true` 仅表示可进入后续内容核对。`queryable`、`automatic_approval`、来源字节验证、OCR 质量验证和身份认证仍为 false；来源声明、真实财务内容及人工批准另有各自要求。
