# 两份观察分别提交，再交给第三个身份复核

数字对得上，并不能证明参考答案本身可靠。这一轮补的是参考观察的记录流程：给两位提交者相同的报表页、行名和年份，各自填写看到的金额、位置、单位和分区依据；两份都提交以后才相互显示，再由未参与填写的复核身份决定是否冻结。

当前目录包含此前使用过的40组查询，对应旧实验的42条登记记录。创建时只复制无答案的任务快照和来源摘要，不预填既有金额、参考框、模型候选或评分。原项目其他公开页面仍可能展示旧答案，这些材料也早已参与开发，因此本实验不能叫盲测或独立测试集。

## 现在的流程

1. 分析员或复核员从服务端目录创建一轮观察，绑定目录摘要和任务快照。客户端不能自报租户、来源或“人工金标准”。
2. 第一份提交后不可编辑。提交者能看到自己的记录，其他身份只能看到已提交状态；不会收到金额、坐标、文本、观察摘要或长度。只有一份观察时，关闭旧轮也不会解除隐藏。
3. 第二个不同的用户身份提交后，两份内容同时显示。系统比较状态、有符号原值、归一数值、金额框、单位、币种及分区依据。自由原因备注保留但不决定一致性，分区补充说明仍属于比较内容。
4. 第三个、未参与提交的复核身份只能在两份内容一致时冻结。换角色不会把同一用户变成另一个人。创建者未参与观察时可以复核；参与过则不能复核或关闭自己的轮次。
5. 两份有分歧时，不能强行改为一致。复核者可关闭本实验，写明理由，再另开新轮。已冻结的参考候选也可以另开修正轮，旧导出不变，新轮不复制旧观察、不自动替换旧评测参考。

流程状态为 `awaiting_first`、`awaiting_second`、`agreed`、`disagreed`、`frozen`、`closed`。只有冻结状态可导出。若两份都登记为不足、歧义或不可读，也可以形成同状态的一致候选，但不会变成“已找到金额”。

一致性采用严格字段比较，包含原值写法和坐标，不是只比归一后的数字。两人对同一位置略有不同的画框也会形成分歧，需要检查后另开一轮；当前没有模糊容差或自动裁决功能。

## 来源变了，怎样恢复

提交观察与冻结前后都会读取当前服务端目录，与创建时的目录摘要和任务快照比较。登记变动或不可读时，内容写入与冻结停止，不偷偷切换材料。前后读取用于发现检查期间变化，不是文件系统锁，也不保证检查完成后文件永远不变。

读取历史记录、回放同一幂等请求、导出旧冻结候选，不需要当前目录继续存在。未参与标注的复核者仍可关闭失效旧轮，这个动作只封存保存过的内容。登记恢复后，可以用当前目录创建有前轮链接的新轮，避免一个无法关闭的旧任务占住恢复路径。

同一租户内，幂等键绑定操作、请求内容及调用用户。同键同请求返回当时的响应，第一份提交的旧响应不会在第二份出现后追加对方内容；换调用人或内容会拒绝。每次写入都在SQLite事务中核对版本，竞争同一版本时最多一项成功。已提交观察没有编辑接口，每轮最多两份。

## 验证结果与边界

24项专项测试通过，覆盖真实目录接入、首份内容与摘要隐藏、不同身份约束、跨租户隔离、幂等原响应、版本竞争、目录漂移、离线关闭恢复、旧导出稳定及安全输出。并发控制中，同一版本的两次提交一项成功、一项版本冲突。

[固定复演](../../artifacts/reference-review-replay.json)在临时数据库内走了三轮：第一轮两份虚构金额不同而被拒绝冻结；第二轮两份虚构内容一致，由第三个模拟身份冻结；第三轮验证旧导出不变及目录不可用时仍可关闭。18项检查全部符合预期，包含4份合成观察和1份冻结候选。金额 `123.45`、`456.78`、坐标和身份均为流程夹具，**不代表对应报表的真实内容**，也不是从旧答案自动填入的标注。

独立人工观察和人工金标准仍为0。应用只能分开记录用户身份，无法据此证明背后是不同自然人，也不能证明其未接触旧答案。新轮为空白不代表参与者忘记了前轮。所有记录和导出保持 `independence_not_verified=true`、`human_gold=false`、`automatic_approval=false`。冻结的是待用参考候选，不是财务事实认证或旧实验成绩更新。

保存的摘要可发现字段不一致，不是签名，也不能阻止数据库管理员同时重写内容和全部摘要。本实验没有下载文件、重新识别图片、调用模型或改动主应用数据库。

## 本地复演

```powershell
python scripts/replay_reference_review.py --output reference-review-replay-new.json
python -m unittest tests.test_reference_review_store
```

脚本只在系统临时目录创建隔离SQLite数据库，结束后清理；报告只能在 `.run/reproductions` 直接新建JSON，已有文件拒绝覆盖。来源目录来自既有公开小报告，不读取完整OCR或原PDF。固定时间和编号只用于合成复演，实际服务仍使用正常服务端时间和随机编号。

服务接口由 `ReferenceReviewStore(path, root)` 提供：`list`、`create`、`get`、`submit`、`freeze`、`close`、`export`。本说明不把存储测试当作已完成的浏览器验收。
