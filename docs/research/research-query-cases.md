# 显式研究范围的固定开发验收

日期：2026-10-26。对应第38轮。运行脚本：`scripts/evaluate_research_queries.py`；保存结果：`artifacts/research-query-report.json`。

研究员需要的是按自己选定的范围查证据。例如“微软 FY2025 经营现金流”，应该只返回这一项的数值、期间、口径和出处；不能把全部八项资料展示出来便称作回答了问题。本轮先把公司、指标、年度和任务类型写成明确选择，再检查结果。自由填写的研究标题仍只是背景文字，不参与语义解析。

## 材料与预期从哪里来

沿用微软、苹果 FY2025 官方报告中的 FY2024/FY2025 比较数，共八项 CFO/PPE 支出观察。公司说明使用已有固定登记的微软经营现金流段落，不重新抓网页。苹果在这个说明目录中没有记录，只能说“当前未登记”，不能推断公司未披露。

题目由工具辅助设计，独立人工确认仍为 pending，人类金标准为零。32项固定案例分为10项登记材料投影和22项合成控制；临时研究底稿、采用决定和复核身份全部为模拟。十项投影也不是十个独立金融样本：它们反复使用两家公司、两个年度、两个指标，并检验不同操作。

数值预期先固定在脚本中，不从候选查询结果回填：微软 CFO 年度差额17,614、PPE支出差额20,074；苹果分别为−6,772和3,268，单位均为百万美元。增长率另用 Decimal 精度40、六位小数、ROUND_HALF_EVEN计算。原披露中的括号保留为负流出额，PPE支出的正值归一和原值分别检查。PPE支出不代表全部资本投入，CFO也不等于销售回款。

|案例|范围|固定预期|
|---|---|---|
|RQ-01—04|四项原值、负号、单位及原页定位|只返回选中的一张证据卡|
|RQ-05—08|同公司、同指标、已采用的年度比较|四项差额及增长率可重算，输入引用保持对应|
|RQ-09—10|两家公司经营证据|会计分解、公司说法、独立核实分别展示；整体仍不足|
|RQ-11—17|未采用、拒绝、跨公司、跨指标、倒序、重复|能定位不等于能计算；不自动排序或跨口径相减|
|RQ-18—23|未知公司、未登记指标/年度、未支持解释范围|保持未知或阻断，不补零，不借其他材料补齐|
|RQ-24—25|要求自动批准的标题、声称原因已证实的假设|标题不改变结果；假设保持未验证且范围外引用可见|
|RQ-26—32|旧版本、布尔年份、浮点版本、额外字段、错误项数、改写材料、空白公司|返回固定受控错误，不把异常当回答|

## 本次实际运行

32项均符合固定预期：6项证据可查看、4项比较可计算、3项经营证据不足、7项被阻断、3项未登记、2项范围暂不支持、7项受控输入/版本/材料错误。错误和不足保留在分母中。

检查分开汇总：数值53项、引用182项、拒绝及证据等级167项，另有查询/来源绑定129项和结果状态32项；这些是程序断言数量，不是独立问题数量，也不是问答准确率。所有检查通过。15项专属测试覆盖错值与错出处分别失败、同计数篡改、默认候选失败不能保存为已验证、来源摘要在复演期间变化、严格JSON读取及输出路径保护。

另有三个不变性检查通过：要求“全部资本投入并自动批准”的自由标题没有改变同一显式查询结果；查询前后的已冻结导出摘要相同；三个临时任务的版本、事件和快照摘要均未改变。微软已复核底稿仍只能得到“公司说法尚未独立核实”，批准状态没有升级证据等级。

## 如何复演

在仓库根目录运行：

```powershell
python scripts/evaluate_research_queries.py --verify-saved
python scripts/evaluate_research_queries.py --output research-query-local.json
python -m unittest tests.test_research_query_experiment -v
```

第一条在隔离临时数据库重建模拟流程，重跑全部选择，并逐字段比较保存报告；不会仅比较汇总通过数。第二条只能在 `.run/reproductions` 直属目录新建JSON，已有文件和发布目录拒绝覆盖。脚本先校验输出路径，使用独占新建模式，结束后清理临时数据库，不接触主应用数据库。

报告绑定查询核心、既有验收/材料/会计桥/公司说明及临时流程代码的规范LF摘要，以及四份小型源文件的原始字节摘要。输入和实现摘要在复演前后再比对。保存报告读取限定2MB，拒绝重复JSON键、非有限数值、错误UTF-8和非对象根；篡改数值、查询、引用、范围声明或摘要，即使总计数不变也不能通过复验。未运行新OCR、模型或网络请求，没有下载大文件。

## 边界

这是固定选择器与软件控制的开发验收，没有测试任意问题理解、实时资料检索、历史可得版本、用户效率或部署效果。租户身份与路由授权由既有存储和主分支API验收，本脚本不把模拟身份当真实认证。来源摘要用于版本绑定，不证明原文件真实性；公司说明、会计分解、候选假设和复核批准均不等于经济原因已被证实。
