# 按证据用途区分锚点与金额：第34轮契约

本轮使用者任务仍是给出行名和年份，从整页识别结果中找出金额。输入没有参考金额、参考框、报表分区或事实对象。这里处理已观察过的开发材料，不是新增盲测，也没有训练或重新运行识别模型。

旧词级方法同时约束金额字词与表头字词。对于已经有可靠整行文字的行名、年份和单位，未参与取数的细词缺陷可能阻断整个查询。新版把这些角色明确分开：整行锚点按原规则定位，金额仍检查完整父行和每个原词。保留原行方法与原词方法的完整结果，方便看到放行与回退来自哪一条规则。

## 接口与边界

`lookup_role_table(page: WordPage, *, row_label: str, year: int)` 返回 `schema_version=1`、`rule_version=role-table-lookup-1`、`query`、`methods.line/word/role`、`scope` 和固定为 false 的 `automatic_approval`。`lookup_role_layout` 只返回新方法。

新方法保留旧词方法的选中值、单位原文、金额/年份/行名证据、父行、来源映射和拒绝理由字段，增加：

- `evidence_roles.line_anchors`：原整行索引及行名、单位、年份表头角色；`amount_parents` 是金额父行索引。
- `nonblocking_anchor_issues`：未被用于取金额的锚点原词有哪些文字、分数、位置或缺失问题。问题仍公开；不据此改写原行文字或框。
- `prefix_associations`：完整会计式前置美元符号的归属、原词引用、年度列、左侧屏障、实际间距及两种框。

锚点和金额父行不重叠。锚点整行分数仍须至少0.90；金额父行及所有原词分别须至少0.90。分数只是识别器输出，未校准为正确概率。金额原词必须严格位于父框内，不允许0.5点或其他容差修复。每个相关父行必须有完整原词，去除空白后与父行全文守恒；不能删掉负号、括号、货币标记、其他列数字或未知文字。无关页脚的词缺陷不阻断本查询。

## 两种金额组

普通组沿用旧方法：每个年度列恰一个完整数字，只支持同一父行内的符号组合，间距上限8点。保存原词和联合框；跨父行的负号、括号或不明标记不由新例外合并。

新增会计式行只接受完整的交替序列：每个表头年度列恰一个单独的前置 `$` 和一个完整数字词，所有金额父行的所有词必须被使用且不重复。数值按原年份列几何唯一分配；首个符号必须位于行名右侧、数值左侧，以后符号必须位于前一数字右侧、当前数字左侧。符号与数字须同行且不重叠。缺一列、未配对尾符号、两个符号、混入其他文字或标记、跨列数字、低分或父词不守恒均拒绝。

这不是把普通8点阈值调大。新增完整行语法不设置最大符号间距，依靠原列归属、屏障、顺序与全词唯一使用约束。间距记录在结果中，可检查宽空白是否合理。`$` 仅是该语法支持的标记，不证明币种是USD；结果币种仍为空。

一个父行可能写成“金额 `$`”，但其中末尾符号只有在完整全行唯一配对证明它是下一列数值的前置符号时，才用于下一组。原父行全文和全部原词同时保留；不截断父行、吞掉尾符号或用参考答案寻找子串。

## 双框与可复算来源

普通派生组的 `origin=derived_word_group`，框是所有组内词的联合框。会计式组的 `origin=derived_accounting_cell`：派生 `span.bbox` 与 `prefix_associations.numeric_bbox` 是原数值词框，仅用于年度列归属及位置评分；`display_bbox` 是 `$` 和数字的完整联合框，供界面展示整个组。数值框不能被描述成完整“符号+金额”的原文范围。

两种组的文字均保留全部所用原词，分数取原父行与原词的最小值。`source_map` 给出每个被引用派生span的原父行和原词索引；`parent_evidence` 保留相关父行的全部词及其真实分数、文字和位置。`mapping_scope=referenced_spans_only` 明确这不是整页识别结果副本。保存的派生页摘要支持一致性绑定，重跑整页算法仍需要完整WordPage。

## 验证与限制

专属测试覆盖：旧两法原样保留且输入不变；锚点原词问题可见但不改行；锚点整行和金额父词低分仍拒绝；金额越父框、丢负号、缺词、重复标签、缺单位/年列；完整美元行、负数与负零；跨父行尾符号的唯一归属；额外/错币种/缺列/重叠/跨屏障/不同行的拒绝；数值框和完整展示框分别可回查。

新方法包含角色分工与会计式序列两项变更，不能把全部变化归因于更细的位置，也不能把已观察材料的成绩当独立泛化能力。选中是候选，不是事实采用、人工复核、文件真实性证明或自动批准。本文不预写42项正式实验成绩；完整对照由独立实验分支记录，所有不足保留。
