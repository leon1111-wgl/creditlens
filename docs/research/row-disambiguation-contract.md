# 显式选择同名行：第35轮核心契约

一张财报里可能出现多处同名项目。只给“行名和年份”时，程序无法知道使用者想看哪一个会计范围。本轮把这些行全部列出，附上附近原文，由调用方明确选择。选择只解除行名歧义；金额取数、采用和复核是后续不同环节。

## 输入与目录

`enumerate_row_candidates(page: OcrPage, *, row_label: str, year: int)` 使用整页行级识别结果。若上游持有 `WordPage`，应传它的 `line_page()`；本模块不检查原词，也不调用词级方法。没有参考金额、参考框、事实对象或分区参数。

目录包含 `schema_version=1`、`rule_version=row-disambiguation-1`、原查询、`input_binding`、候选数量、全部候选、旧行级方法结果、范围说明和固定 false 的 `automatic_approval`。每个候选保存：

- `row_index`：原页 `spans` 中从零开始的索引，不是按金额、得分或纵向位置重新排序的编号。
- `row`：完整原行及其索引；所有规范化后完全同名的行都保留。
- `context.above/below`：几何上最近的上方／下方各最多4个完整原span，保留索引。排序依次为垂直间隔、横向位置、原索引；不判定财务分区或对邻近文字作语义归因。
- `extraction`：以该行为候选的整行取数预览，可以选到值，也可以证据不足。预览不代表已经明确选择这行。

没有候选时目录状态为 `not_found`。一个或多个候选均为 `selection_required`，从不默认第一个或唯一一个。`legacy_line_result` 保留未显选时原方法的结果，不能用新流程回写旧冻结成绩。

## 选择绑定

`lookup_selected_row(page, *, row_label, year, selection=None)` 接收严格的两字段选择：`{input_sha256, row_index}`。`None` 仍返回待选目录，顶层 `selection` 和 `extraction` 为 null。合法显选返回完整目录、`selection`（附 `explicit=true`）、所选 `extraction`，顶层状态沿用该候选的 `selected` 或 `insufficient`。

`page_sha256` 是完整规范化 OcrPage 的规范JSON摘要；`input_sha256` 是 `{rule_version, page_sha256, query}` 的规范JSON摘要。`query` 包含页号、原始行名、规范化行名和年份。因此金额、无关页脚、行序、页面尺寸或查询变化，都会使旧选择失效；连仅改变原查询大小写也要重新取得绑定。不能用 bool、字符串或浮点数冒充行索引，不能传额外字段、越界索引、非候选索引或过期摘要。

错误由 `RowDisambiguationError(code,path,message)` 报告，代码包括 `invalid_selection`、`invalid_selection_digest`、`invalid_row_index`、`row_index_out_of_range`、`stale_selection` 和 `selection_not_candidate`，以及受控的页面／查询格式错误。不把输入文字拼进异常说明。

该摘要只证明这一页和这次查询的一致性，不是签名或真实性证明。来源PDF、图像、原WordPage、登录身份与租户的绑定由服务器／实验登记层负责；纯核心不宣称验证了这些身份。

## 选择后仍然检查什么

核心在**原始完整页**上运行冻结行布局方法的后半段，仅把原来的“唯一行名”门槛替换为合法的显选行索引。没有删除、改名、重排其他同名行，也没有构造一个移除了歧义的新页面再调用旧方法。

单位唯一、单位例外、适用年份表头组、完整年份列、整行分数、金额全文语法、同行额外内容、金额列数量和全框归列约束保持原规则。其他同名行若出现在表头上下文或干扰所选行的金额列，仍会导致不足。符号不通过截取子串删除，缺数不填0；完整负数和零保留。百万等量级及货币符号仍不能证明USD，币种保持未知。

这是行级显选流程，不继承新词级方法的原词守卫或会计式跨父行符号支持。选择行也不证明使用者选对了实际财务范围，不能自动采用、审批，不能改称文档验真、语义分区理解或OCR质量验证。

## 验证边界

专属测试覆盖0/1/多候选、两个不同金额路径、原页不变、原索引、几何上下文、每候选独立不足、同名行仍干扰表头／金额、过期页面与其他查询、非候选及非法索引、额外参数、分数／单位／年份／金额列／符号拒绝和负零保留。真实开发页按完整候选路径另行记录，不用旧事实分区选择一条“正确路径”来计算无歧义准确率。
