# 同名财务行：明确选择后的取数复演

本实验处理一个具体问题：同一页出现两个 `Marketable securities` 或 `Term debt`，只给行名和年份无法知道研究员要查哪一行。此前保守返回不足；现在保留两个原行和上下文，要求调用方明确选定原行索引，再在原完整页上取数。这个选择不会自动认定“流动”“非流动”等财务含义。

本实验没有新下载、OCR、模型调用或付费，也没有修改旧参考包、旧规则和原42条评分。实现沿用此前已观察的开发材料，独立人工金标准仍为0。企业工作流依据沿用已注明日期的需求调研，本实验没有新增客户访谈或市场结论。

## 固定范围与实际结果

从按证据用途取数实验完整报告中选出所有 `duplicate_row_label` 查询，而不是挑能成功的案例。旧6条登记记录去重后是4组查询：苹果FY2025报告物理第34页，两种行名各查询FY2024与FY2025。每组保留两个同名原行，共8条显式选择路径。

|查询|第一候选原行索引及原值|第二候选原行索引及原值|
|---|---|---|
|Marketable securities，2025|13：18,763|32：77,723|
|Marketable securities，2024|13：35,228|32：91,479|
|Term debt，2025|64：12,350|71：78,328|
|Term debt，2024|64：10,912|71：85,750|

原行索引是保存OCR中的零基索引，不是PDF印刷行号。这8条路径均返回了数值候选；它们没有被评分为“8个正确答案”。尤其第二个 `Marketable securities` 行不在原42条参考事实中，没有据此补造参考。原6条同名不足及旧42条结果保持原样。

每次选行返回全部同名候选、每行上方和下方最多4个最近的原文字块、完整候选取数证据，以及明确选择的索引。附近文字仅按几何距离排列，不是模型识别的报表分区。没有选择时，取数值与选择字段都是空值；即使合成页只有一个候选，也不隐式选中。

## 输入绑定与保存检查

实验先校验已有6份完整WordPage的文件摘要、规范内容摘要、页尺寸、行词数和父行投影，再从其中的苹果第34页执行4组查询。提取器只得到整页行级OCR、行名、年份与显式选择；旧参考金额、框、分区及 `fact_id` 不参与选择。

选择绑定完整行级页、原始查询和规则版本的摘要。改年份、换页内容、布尔行号、非候选索引、越界索引或附带参考答案字段均拒绝。选定行后，原有年度列、单位、金额完整语法及置信度守卫仍执行，不会删去其他行或过滤干扰证据。

公开报告保留必要原行、上下文和候选轨迹，不公开完整OCR、原PDF或页图。`--verify-saved` 校验发布文件摘要、来源及实现版本、旧同名行全集、所有选择路径，并用公开可见片段重算局部取数与上下文关系。它不能证明未公开的整页没有其他干扰，也不声称重新跑过OCR。完整提取复演必须显式提供保存的6份WordPage，逐字段比较整个报告。

配置绑定旧报告与输入登记；代码使用UTF-8、LF规范摘要；报告及发布清单使用实际UTF-8 LF文件摘要。范围、来源、计数、候选清单、选择关系和布尔/整数类型的改写不能靠保持总数不变通过保存检查。

## 独立开发控制

15项合成控制单独计数，全部满足预先固定的预期：不默认选择、明确选择两个不同原行、年份或页内容变动后旧选择失效、非法索引与额外答案字段拒绝、缺金额与低分仍不足、完整括号负数保留、唯一候选仍需选择、无候选和额外货币符号守卫。合成值与OCR修改只用于工程控制，人工确认状态为pending，不是模型准确率或新金融基准。

18项专属测试覆盖完整候选与路径、先取数后参考边界、来源与代码漂移、同计数变异、上下文关系、类型替换、公开核验不读完整OCR，以及新文件输出和拒绝覆盖。独立复放流程另外检查6份完整WordPage，报告逐字段一致；并核对候选遗漏、路径遗漏、金额变化、上下文换侧和3类同值类型替换均被拒绝。

## 复现

仅验证公开保存结果：

```powershell
python scripts/evaluate_row_disambiguation.py --verify-saved
```

从已有完整OCR重做所有路径并另存新文件；目录缺失会失败，不自动下载：

```powershell
python scripts/evaluate_row_disambiguation.py --ocr-root .run/reproductions/document-ai-words --output row-disambiguation-local.json
```

输出只允许直接位于 `.run/reproductions` 的新JSON，禁止覆盖已有文件、公开产物和登记预览。若要对某份报告做完整输入复放，可调用 `validate_row_disambiguation_report(root, report, ocr_root=...)`；校验要求整个结果相等，不只是计数相等。

下一步是把明确选择的行与实际研究任务、报表分区依据和独立参考观察衔接。本实验没有身份审批、财务采用或自动入库，币种及完整期间证明也不因选行成功而自动成立。
