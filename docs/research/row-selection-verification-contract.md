# 显式选行导出的冻结登记核验

第36轮补充一个只读检查：把第35轮显式选行接口下载的原始JSON，与安装仓库中**已经校验的冻结报告**逐字段比较。上传文件提供的来源链接、报告摘要或重新计算的哈希都不能代替这个可信来源。

## 三个入口与边界

- `parse_selection_bytes(raw: bytes) -> dict`：最大128KiB，严格UTF-8 JSON对象；拒绝重复键、NaN、Infinity、溢出、过深结构、过多节点、孤立Unicode代理字符和不可安全往返的数字字面。容器最大64层、总值节点最多20000；数值字面最多1024字符。不会把 `1e-9999` 静默变为0，或把超出浮点往返精度的不同小数变成同一登记值。
- `verify_row_selection(payload: dict, snapshot: dict) -> dict`：纯比较函数，`snapshot` 必须由可信调用方通过 `load_row_disambiguation_snapshot(root)` 取得，不能取自上传内容。非JSON对象仍受控拒绝；合法JSON中的字段、类型或内容差异返回 `mismatch`。
- `load_and_verify_row_selection(raw: bytes, root: Path) -> dict`：先检查输入，再加载固定登记并比较，同时记录本次输入字节摘要。不会读取上传URL、重跑OCR、写数据库或采用事实。

辅助函数 `expected_selection_payload(snapshot, query_id, row_index)` 从可信报告构造与旧GET接口相同的16字段响应，供独立复演与测试使用，不新增批准或身份。

## 比较规则

按查询ID和显式原行索引查找**唯一已登记路径**，重建原响应的报告／上游报告摘要、来源、页面元数据、查询、完整候选目录、显选结果和全部范围标志。逐字段检查所有值，字典键顺序和JSON空白可以变化；列表顺序、缺键、额外键、数值类型不能变化，`true`、`1`、`1.0`分别处理。浮点负零也不悄悄等同正零。

整包金额和内部副本一起改写、再计算上传者自己的所有摘要，仍无法与冻结响应相同。未知结构／规则版本、未知报告、未知查询与未知行分别返回稳定代码。最多返回16个差异，另有 `issues_truncated`；错误路径只引用可信结构字段或其父位置，不把未知上传键名、原值或本地路径写进诊断。

输入错误类为 `RowSelectionVerificationError(code,path,message)`，`http_status` 为400；超128KiB为413。已安装来源不可用、改变或无法校验时，由 `RowSelectionSourceError` 区分，供接口409处理。不能在来源失效时转而信任上传文件的自述。

## 返回内容

结果包含 `schema_version=1`、`verification_version=row-selection-verification-1`、`status=matched/mismatch`、`issues`、摘要依据和范围限制。`trusted_report_sha256` 来自可信来源；`bound_selection` **只有整个响应匹配时才出现具体绑定**，包含可信报告／查询／文档／页／原行及输入摘要，差异时为null，避免把不可信上传身份写成已确认身份。

`raw_sha256` 是本次收到的原始字节摘要；纯字典入口没有原始字节，因此该字段为null。`canonical_sha256` 对当前解析对象按 Python JSON（键排序、保留Unicode、紧凑分隔符、禁止非有限数）计算。它保留整数与浮点数表示区别，不是签名。

`scope` 固定为只读、不持久化、未重放完整OCR、未检查源文件字节、未验证真实性、未独立验证财务正确性、没有人工gold、没有自动批准。结果不回传整份上传文件。

## 必须保留的限制

完整替换为**另一条合法登记路径**仍会通过，并绑定到那条路径。这是预期行为：没有预先可信的收件摘要或数字签名，系统无法证明某个历史原件从未变化，也不能证明谁生成或上传了文件。成功只表示“记录与当前登记的选择结果逐字段一致”，不是文件防篡改验真或财务正确性评分。

纯比较函数也不能证明传入的 `snapshot` 来自可信服务器；应用必须使用安装仓库的固定loader，不能开放上传snapshot替代参数。调用方的认证、租户隔离和上传权限仍由API负责。

## 验证

专属测试使用全部8条真实登记路径，并直接比较旧GET接口的响应形状；覆盖自洽重算哈希、来源和原行变更、布尔／整数／浮点替换、候选删减、批准标志、未知版本、字段增删、错误限额、字节／规范摘要区别、合法整包替换、严格JSON解析及来源不可用。解析失败应发生在来源加载之前。没有下载材料、模型调用或新人工标注。
