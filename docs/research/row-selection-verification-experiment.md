# 导出的选行结果还能否对应冻结证据

研究员把选行结果保存成JSON、交给同事或稍后重新打开时，需要知道其中的金额、查询、来源和候选清单有没有变化。本实验新增本地核验入口：读取原导出文件，与已校验的冻结报告逐字段比较；相同则显示对应的已登记选择，不同则列出差异。原有GET导出没有增加字段，旧结果及评分保持原样。

这一步检查的是“是否仍是这份保存结果”。它不认证上传者，不验证官方文件真伪，不判断选中的财务口径是否符合研究目的，也不把数值候选变成独立人工金标准。换成另一份完整、合法的已登记选择仍会匹配；工具不能据此判断是否符合某个人原来的意图。

## 输入与可信来源

读取器最多读取128KiB再加1字节，先检查字节上限和严格JSON，再加载冻结来源。重复键、非有限数、过深嵌套、非法UTF-8和孤立Unicode代理项会被拒绝。布尔、整数、浮点类型不能因为Python数值比较相等而互换。

上传文件中的报告摘要只是待检查字段，不能替代可信来源。工具从安装仓库加载已校验的同名行选择报告，再构造该查询和原行索引对应的完整旧响应，比较金额、所有候选、上下文、页登记、来源、查询与只读状态。上传方同步改数字、复制处和自报摘要，也不能改变安装仓库中的冻结报告。

若安装登记缺失或失效，结果是“可信来源不可用”，不会自行接受上传文件或从其URL下载材料。错误摘要不回显未知字段名、原文内容或本机文件路径。

## 固定复演范围

基线是同名行选择的4组查询、8条选择路径的原响应结构。实验根据冻结报告构造同结构输入，不称为已发起8次真实HTTP请求；实际端点响应须另外核对。8份封套的匹配只说明保存内容一致，不是8个金融答案正确。

34项合成控制单独计数：23项合法JSON内容修改、9项格式或大小错误，以及2项保留内容的正例。修改覆盖金额、来源链接和摘要、图片登记、查询年份与行名、选中行、未选候选、附近原文、未知或缺失字段、布尔与数值类型、伪造哈希、整包同步篡改，以及虚构可写、持久化或批准状态。正例允许对象键顺序和空白变化，也检查恰好128KiB的合法输入。所有预期在调用候选实现前写入代码；格式拒绝也是预期结果，不能从分母删除。

正式运行中8份登记封套全部匹配，34项控制全部符合预期：23项内容不符、9项输入拒绝、2项保留内容的匹配。16项专属测试通过。公开报告为84,892字节，未保存完整导出负载；没有为取得通过结果删除失败或改动旧规则。

公开产物只保存输入字节长度、摘要、预期、实际核验结果与受控差异路径，不保存上传JSON正文、完整OCR、PDF或数据库。原始字节摘要与规范内容摘要分别显示：空白变化可使前者不同、后者相同。这些哈希不是数字签名。

实现和报告绑定旧选行报告摘要、上游报告摘要及实际执行源码的UTF-8 LF摘要。保存报告核验会重新生成8份封套、重做全部34项控制，并逐字段比较结果，不只看通过数。遇到任一意外控制结果，不生成“已验证”报告。

## 命令行与退出状态

检查已有文件，默认只向标准输出返回小型核验结果：

```powershell
python scripts/verify_row_selection.py --input path/to/selected-row.json
```

可另外保存核验摘要，但仅允许 `.run/reproductions` 直接目录下的新JSON，不覆盖输入、公开报告或登记预览：

```powershell
python scripts/verify_row_selection.py --input path/to/selected-row.json --output selection-check.json
```

重新执行固定开发控制，或重验公开报告：

```powershell
python scripts/verify_row_selection.py --run-controls --output selection-controls-local.json
python scripts/verify_row_selection.py --verify-saved
```

|退出码|含义|
|---|---|
|0|逐字段匹配，或固定控制/保存报告复演通过|
|1|文件是可解析对象，但与冻结响应不符|
|2|输入格式、文件读取或输出路径错误|
|3|可信来源不可用，或本次核验没有完成|
|4|输入超过128KiB|

没有业务数据库写入、网络请求、新OCR或模型调用。已存在文件不会被覆盖；JSON格式错误先返回，不会为了检查坏输入而加载来源目录。

## 验证边界

专属测试覆盖8份旧响应形状、全部控制分母、同计数篡改、保存报告复算、只读输入、单次有界读取、格式先行、退出状态、差异脱敏，以及输出保护。完整OCR复演不是本实验操作；同名行选择报告中公开证据的局部验证限制继续保留。研究和业务背景沿用已有注明日期的调研，本实验不新增用户访谈、模型成绩或生产部署声明。
