# 字词级表格取数契约

本实验回答一个具体问题：OCR 把相邻年度金额合成一行时，能否利用保存的字词位置恢复列关系，同时保留原行级方法的结果和失败证据。输入仍是整页 OCR、完整行名与年份，不给提取器参考金额、参考框、财务事实或报表分区。

`word-table-lookup-1` 是独立版本。旧 `table-lookup-1`、旧 OCR、旧参考包与旧实验报告保持不变。当前材料是已经观察过的开发材料，不能将本实验对照称为新发行人盲测或新的模型识别成绩。

## 接口

```python
lookup_word_table(page: WordPage, *, row_label: str, year: int) -> dict
lookup_word_layout(page: WordPage, *, row_label: str, year: int) -> dict
```

前者返回 `schema_version`、`rule_version`、`query`、`methods.line`、`methods.word`、`scope`、`automatic_approval:false`。`line` 直接调用原方法处理同一份 `WordPage.line_page()`，结果不改写。`word` 在临时派生页上沿用原布局方法，并增加下述守卫。后者仅返回 `word` 对应结果。非法模型或查询沿用 `TableLookupError(code,path)`；证据不足返回有固定中文说明的 `insufficient`。

## 如何取数

先按原行级规则找唯一行名、单位说明和适用年份组。重复的同名行、缺失年份、多个表头及单位例外仍然不足，字词位置不能替查询补出一个分区。

随后检查相关父行的全部字词。相关范围包括行名、单位、表头、原方法引用的证据，以及父框或词框位于该金额行且在行名右侧的父行。因而移位的父框不能藏住还在金额行里的词，无词父行也不会被静默丢弃。无关页脚低分不会令整页失败。

每个相关父行必须同时满足：

- 有字词记录，父行文字与按原顺序连接的全部字词去掉空白后完全相同；不删除标点、负号、括号或货币符号。
- 每个词框严格包含在父框内，容差为零。本实验不修正历史输出中的半点越界；如果相关证据存在越界，如实保留不足。
- 父行分数和每个原生词分数均至少 `0.90`。不使用会替换词分数的旧 `token_page()`；两类分数都不是校准后的正确概率。
- 金额父行的全部词都在查询行，原词顺序与从左到右的几何次序相符，词框不互相重叠。

年份列范围由原表头中心的中点确定。每个金额词必须完整落入唯一列，所有词必须归属，所有年份列必须有完整金额。同列只能有一个可独立解析的数值词；不得把两个数字词拼成新数值。附加词只支持 `$`、`¥`、`￥`、正负号和括号，完整拼接后的文本必须通过原有完整金额语法。货币符号保留在原值中，但不证明具体币种，输出的 `unit.currency` 仍为 `null`。

同一金额内的符号和数值只允许来自同一个守恒父行，邻词间隔不超过固定的 8 PDF 点。跨父行的孤立负号、括号或货币符号暂不关联。这个限制可能保留原本能够人工理解的不足；规则不能为了使开发材料通过而删掉尾部 `$` 或忽略邻列符号。

全部关系通过后，将该行的金额父行替换为每列一个派生 span。每个 span 的文本为按横坐标排序后的 `''.join(word.text.strip())`，框为所用词框的并集，分数为所用父行和原生词分数的最小值。其余原始父行保持原样。派生页只在内存中使用，再交给原布局方法判断；没有新 OCR 或模型调用。

## 返回的证据

单方法结果保留原接口中的 `status/reason/message`、原值与归一值、`unit`、`column`、`selected_span_index` 和 `evidence`。证据仍按 `row_label/year_headers/unit/amounts/guards` 分组，每项为 `{span_index,span}`。

新字段说明：

| 字段 | 含义 |
| --- | --- |
| `selected_span_origin` | 选中时为 `derived_word_group`，不足时为空。索引属于派生页，不能称为原始 OCR 行号。 |
| `parent_evidence` | 所有相关或引用父行的原始 `line_index/line`、全部原生 `words` 及其词索引、文字守恒和几何检查结果。不是只保留选中金额的词。 |
| `guard_issues` | 固定问题代码、原父行索引及词索引；失败仍保留证据。 |
| `adaptation.status` | 是否实际构造了临时派生页，不代表候选正确或获批。 |
| `adaptation.line_input_sha256` | 同输入行级投影的规范 JSON 摘要。 |
| `adaptation.derived_page_sha256` | 完整临时派生页的规范 JSON 摘要；未适配时为空。 |
| `adaptation.source_map` | 结果实际引用的 span 到原父行和原词的映射；`mapping_scope` 固定为 `referenced_spans_only`。 |
| `confidence_basis` | 明确同时检查父行与原生词分数，且两者未校准。 |

公开片段可以重算局部文字、框和分数的派生关系，不能替代完整 WordPage 的提取重跑。报告中的 line/word 对照同时改变了输入粒度和额外守卫，不能把全部变化都归因为位置更细。

## 本次验证范围

本模块的 23 项合成回归覆盖：正常同输入对照、合并金额分列、同父行货币符号、合法负数和负零、符号丢失、父框移位及半点越界、空字词、父行与词分数分别不足、无关低分页脚、重复行名、缺少单位或年份、同列多数字、未知文本、尾部符号、跨父行符号、间隔和重叠、跨列、缺列、重复金额、跨行内容、来源映射和调用者模型绕过。测试使用人工构造的 OCR 结构，不衡量真实模型识别准确率。

真实六页、42 项开发查询的比较由独立实验流程在核心版本固定后运行，保留所有旧不足、新不足及回退。核心规则和合成回归不代替真实材料的完整对照。
