# 同一份 OCR 的行级与受保护词级取数对照

本实验继续研究给定报表页、行名和年份后怎样取出正确金额。使用此前保留的微软、苹果六份 WordPage，没有重新下载、运行 OCR、调用模型或付费训练。基线使用 WordPage 的 `line_page()`，新方法使用其原词及父行，并增加文本守恒、父词几何、符号归属和原生分数守卫。

新方法同时改变了取数粒度和守卫条件，因此这个对照不能隔离“仅使用词框”的效果。规则先提交，再运行完整材料；参考金额、参考框和分区答案均不传入提取器。全部候选完成并固定摘要后，才用旧参考的有符号金额和框评分。

## 先确认输入是否变了

六页共有 725 个父行、1,381 个原生词。本实验逐页核对完整 `line_page` 的规范摘要，六份投影均与整行取数实验行级 OCR 一致；基线的42条提取结果也与整行基线完全相同。配置还绑定旧词级公开记录、原 PDF 来源摘要、原图摘要及原生词文件的原始和规范摘要，不单凭投影相同判断文件身份。

登记参考共 **42 条记录、40 组不同查询**。苹果 FY2024、FY2025 的 `Term debt` 查询各对应流动与长期两条参考；输入相同，无法通过行名区分分区。本实验强制同查询组的完整提取摘要相同，保留两份参考作后置对照，不把 `fact_id` 或分区偷偷交给提取器。40组也仍是已观察开发查询，不是独立人工盲测。

## 实际结果

2026-10-26 在固定规则后完整运行，结果如下。

| 方法 | 金额和位置匹配 | 错取 | 不足 | 全部登记记录 |
|---|---:|---:|---:|---:|
| 同输入的行级基线 | 26 | 0 | 16 | 42 |
| 受保护词级方法 | 22 | 0 | 20 | 42 |

逐项转移，而不是只看净总数：

| 行级 → 词级 | 匹配 | 错取 | 不足 |
|---|---:|---:|---:|
| 匹配 | 22 | 0 | 4 |
| 错取 | 0 | 0 | 0 |
| 不足 | 0 | 0 | 16 |

没有新增匹配，旧的16项不足全部保留。四项回退是微软两年的短期债务与苹果两年的收入。微软两项触发原词框超出父行框（`word_outside_parent`）；苹果两项的首要原因是原生词分数低于门槛（`word_low_confidence`），同时也触发原词框超出父行框。报告保留全部守卫原因，不只展示首要原因。父词包含关系仍使用零容差，父行和原生词都使用0.90门槛，未为这四项放宽。它们需要进一步核对识别坐标与分数，不能据此认定财务数字有误。

七个合成开发控制另行统计，全部符合预先规定的词级结果：正常独立金额、同父行合并两列、原词缺失、父框移位、父词负号不守恒、低原生词分数、重复行名。正常与合并列是正控制，其余保持不足；合成材料不加入42条真实参考记录的分母，也不作为真实样本增益。

## 候选怎样留下依据

选中的词级候选是派生词组，记录其原父行、全部原词、词索引、派生框及来源映射。派生文本按横向位置连接各词去首尾空白后的全文，框为这些词的并集，分数取所有相关父行和原生词的最小值。完整符号必须保留，不能按参考金额截取片段。

公开映射只包含实际引用的派生跨度，所有相关父行的原词仍完整保留；完整派生页面仅记录规范摘要。报告检查器会复算可见父词文本守恒与几何关系，核对词索引、派生文本、框及分数，拒绝结构外的自报“已验证”字段。即便派生分数被同步改成一个自洽的低值，也不能维持选中状态。

局部关系核验不证明未公开的整页不存在其他内容。只有显式读取原六份 WordPage 才能复放完整提取过程。金额匹配不升级为币种、完整财务期间或业务批准；原生分数和父行分数都不是已校准的正确概率。

## 已完成的验证与复现

- 19项实验测试通过，包括参考金额/框隔离、42/40分母、完整转移矩阵、同查询输出一致、公开父词与派生关系重算、低分自洽篡改拒绝、安全输出和只读API边界。回归检查发现守卫词引用可以指向另一已公开父行后，补上引用必须属于该条守卫父行且不得重复的检查；自洽改摘要也不能绕过。
- 用六份原 WordPage 重新执行提取，与[正式报告](../../artifacts/word-table-lookup-report.json)逐字段一致。
- 公开报告约524 KiB，采用紧凑JSON保存完整必要上下文；[发布登记](../../configs/word-table-lookup-artifact.json)固定字节摘要。不含原 PDF、页图或完整 OCR。

独立人工金标准仍为0，本实验没有验证未见公司的泛化、任意问句理解或用户效率。当前结论是更细粒度与更严格守卫并未增加这批材料的可取数覆盖，后续应先独立核对失败来源、标注坐标与分数，再评估是否调整方法。
